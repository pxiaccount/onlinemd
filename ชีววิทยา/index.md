# 🦠 ชีววิทยา

ยินดีต้อนรับสู่โฟลเดอร์ชีววิทยา — เลือกหัวข้อด้านล่างเพื่อเริ่มทบทวนได้เลย

## 📚 หัวข้อทั้งหมด

### 🦠 จุลชีววิทยา

- 🦠 [[การแบ่งตัวของแบคทีเรีย]] — เปรียบเทียบ binary fission vs conjugation พร้อมตาราง ตัวอย่าง และโจทย์
- 📅 [[โจทย์การนับวันรอบเดือน]] — โจทย์ 10 ข้อ นับวันไข่ตก ระยะเสี่ยง รอบไม่คงที่ พร้อมเฉลย

### 🐣 การเจริญเติบโตของสัตว์ (ม.5)

ชุดโน้ตจากสไลด์ ครูธนาวุฒิ คำประเสริฐ (โพธิสารพิทยากร) — ครบทุกระยะของเอ็มบริโอ พร้อม SVG ประกอบทุกไฟล์

1. 🧬 [[การเจริญเติบโตของสัตว์]] — ภาพรวม: growth vs development และ 4 ขั้นตอนจากไซโกต (เริ่มอ่านที่นี่)
2. 🍞 [[คลีเวจ]] — แบ่งเซลล์เพิ่มจำนวนจนได้โมรูลา + ประเภทไข่แดง 3 กลุ่ม
3. 🎈 [[บลาสทูเลชัน]] — เกิดโพรงบลาสโทโคเอล + บลาสโทชิสต์ของมนุษย์
4. 🥞 [[แกสทรูเลชัน]] — จัดเซลล์ 3 ชั้น + อวัยวะจากแต่ละชั้น + โพรโท/ดิวเทอโรสโตม
5. 🏗️ [[ออร์แกโนเจเนซิส]] — สร้างอวัยวะ หลอดประสาท และนอโทคอร์ด
6. 🐸 [[การเจริญเติบโตของกบ]] — ไข่กบ ลูกอ๊อด และเมทามอร์โฟซิส
7. 🐣 [[การเจริญเติบโตของไก่]] — โครงสร้างไข่ + ไทม์ไลน์ฟัก 21 วัน
8. 🛡️ [[เยื่อหุ้มเอ็มบริโอ]] — amnion, chorion, yolk sac, allantois
9. 👶 [[การเจริญเติบโตของมนุษย์]] — ฝังตัว ไตรมาส รก สายสะดือ และการคลอด
10. 📈 [[อัตราการเติบโตของสัตว์]] — กราฟขั้นบันไดแมลง + อวัยวะโตไม่พร้อมกัน
