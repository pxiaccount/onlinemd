# คำเชื่อม (conjunction)

> [!abstract] สรุปในหนึ่งบรรทัด
> คำเชื่อมคือ "กาว" ที่ใช้ติดคำ วลี หรือประโยคเข้าด้วยกัน โดยแบ่งตามหน้าที่หลักได้ 4 กลุ่ม คือ **เหตุ–ผล · ขัดแย้ง · เงื่อนไข · เวลา–เพิ่มเติม** และจุดที่ข้อสอบชอบหลอกที่สุดคือ **although ห้ามใช้คู่กับ but** และ **because ห้ามใช้คู่กับ so**

## 🧠 ทำความเข้าใจ

**ทำไมคำเชื่อมสำคัญ?** เพราะมันคือตัวบอก "ความสัมพันธ์" ระหว่างสองความคิด — เป็นเหตุ เป็นผล ขัดแย้ง หรือเป็นเงื่อนไข ถ้าเลือกคำเชื่อมผิด ความหมายทั้งประโยคก็เปลี่ยนทันที

ลองนึกเทียบกับภาษาไทย: เราใช้ "เพราะว่า" "แต่" "ถ้า" "ดังนั้น" ภาษาอังกฤษก็มีคำเทียบเคียงแบบเดียวกัน

### แบ่งตามหน้าที่ (4 กลุ่มหลัก)

| กลุ่ม | คำเชื่อม | ความหมาย | ตัวอย่าง |
|------|------|------|------|
| **เหตุ–ผล** | because, since, as | เพราะว่า | I stayed home **because** it was raining. |
| | because of, due to, owing to | เพราะ (ตามด้วยคำนาม) | We stayed home **because of** the rain. |
| | so, therefore, thus, consequently | ดังนั้น | It was raining, **so** I stayed home. |
| **ขัดแย้ง** | but, yet | แต่ | I'm tired, **but** I'll finish it. |
| | although, though, even though | ถึงแม้ว่า | **Although** it rained, we went out. |
| | however, nevertheless | อย่างไรก็ตาม | It rained. **However**, we went out. |
| | while, whereas | ในขณะที่ (เปรียบเทียบ) | I like tea, **while** my brother likes coffee. |
| | despite, in spite of | ถึงแม้ (ตามด้วยคำนาม) | **Despite** the rain, we went out. |
| **เพิ่มเติม** | and, besides, moreover, in addition | และ/นอกจากนี้ | She sings **and** plays the guitar. |
| | not only … but also | ไม่เพียงแต่…ยัง | She **not only** sings **but also** plays the guitar. |
| **ทางเลือก** | or, either … or | หรือ | You can take **either** the bus **or** the train. |
| | neither … nor | ไม่ทั้งสอง | **Neither** Tom **nor** Ann came. |
| **เงื่อนไข** | if, unless, otherwise | ถ้า / ถ้าไม่ / ไม่อย่างนั้น | **Unless** you hurry, you'll be late. |
| | in case, as long as, provided that | เผื่อว่า / ตราบใดที่ | Take a jacket **in case** it gets cold. |
| **เวลา/ลำดับ** | when, while, before, after, as soon as, until, by the time | เมื่อ/ขณะที่/ก่อน/หลัง/ทันทีที่/จนกระทั่ง | **As soon as** I finish, I'll call you. |
| **จุดประสงค์** | so that, in order that, so as to, in order to | เพื่อว่า/เพื่อ | I studied hard **so that** I could pass. |

### แบ่งตามหลักไวยากรณ์ (เจอในข้อสอบ)

| ชนิด | หน้าที่ | คำที่ใช้ |
|------|------|------|
| Coordinating conjunction | เชื่อมคำหรือประโยคที่ "เท่ากัน" | **FANBOYS**: for, and, nor, but, or, yet, so |
| Subordinating conjunction | เชื่อมอนุประโยคย่อยเข้ากับประโยคหลัก | because, although, when, if, unless, while, since, until, after, before, as soon as |
| Correlative conjunction | เป็นคู่ ต้องมากันสองตัว | both … and, either … or, neither … nor, not only … but also |

> [!tip] เทคนิคจำ
> - **จำ FANBOYS** = for, and, nor, but, or, yet, so (คำเชื่อมที่เชื่อมประโยคเท่ากัน)
> - **คำที่ลงท้ายด้วย -ever** ให้ความหมายว่า "ไม่ว่าจะ…ก็ตาม" เช่น whatever, whenever, wherever, whoever, however
> - **so vs so that** — so = "ดังนั้น" (ผลลัพธ์) · so that = "เพื่อว่า" (จุดประสงค์)

> [!info] กฎเครื่องหมายจุลภาค (comma) ที่ออกสอบบ่อย
> 1. เชื่อมสองประโยคเต็มด้วย FANBOYS → ใส่จุลภาคหน้า: *I was tired**, so** I went to bed.*
> 2. ขึ้นต้นด้วย although / because / when → ใส่จุลภาคหลังอนุประโยคแรก: ***Although** it rained**,** we went out.*
> 3. ถ้ากลับลำดับ เอา although/because ไปไว้กลางประโยค → **ไม่ต้อง**ใส่จุลภาค: *We went out **although** it rained.*

## ✏️ ตัวอย่างการใช้งาน

| ประโยค | แปลไทย | จุดสังเกต |
|------|------|------|
| I didn't go to school because I was sick. | ฉันไม่ไปโรงเรียนเพราะป่วย | because + ประโยค |
| I didn't go to school because of my sickness. | ฉันไม่ไปโรงเรียนเพราะอาการป่วย | because of + คำนาม |
| Although he is young, he works hard. | ถึงแม้เขาอายุน้อย แต่เขาทำงานหนัก | although + ประโยค (ไม่ต้องมี but) |
| Despite being young, he works hard. | ถึงแม้อายุน้อย แต่ทำงานหนัก | despite + V-ing |
| Study hard, or you will fail the exam. | ตั้งใจเรียน ไม่อย่างนั้นสอบตกแน่ | or = ไม่อย่างนั้น |
| Study hard so that you can pass the exam. | ตั้งใจเรียนเพื่อจะได้สอบผ่าน | so that + ประโยคจุดประสงค์ |
| Both my brother and I like playing games. | ทั้งพี่ชายและฉันชอบเล่นเกม | both … and จับคู่กัน |
| Neither the food nor the service was good. | ทั้งอาหารและบริการก็ไม่ดี | neither … nor = ไม่ทั้งสองอย่าง |

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **although + but ใช้คู่กัน** — ✗ *Although it rained, but we went out.* → ✓ *Although it rained, we went out.*
> 2. **because + so ใช้คู่กัน** — ✗ *Because I was tired, so I slept early.* → ✓ *Because I was tired, I slept early.*
> 3. **despite + ประโยค** — ✗ *Despite it rained, we went out.* → ✓ *Despite **the rain**, we went out.* / ✓ *Although it rained, we went out.*
> 4. **unless แล้วใส่ not ซ้ำ** — ✗ *Unless you don't study, you will fail.* → ✓ *Unless you **study**, you will fail.*
> 5. **สลับคู่ correlative** — ✗ *Both my mother or my father…* → ✓ *Both my mother **and** my father…*
> 6. **ใช้ will ในอนุประโยคเวลา/เงื่อนไข** — ✗ *When I will arrive, I'll call you.* → ✓ *When I **arrive**, I'll call you.*

> [!important] จำแบบนี้ไม่มีพลาด
> - **although / though / even though / because / when / if** → ตามด้วย **ประโยค** (มีประธาน + กริยา)
> - **despite / in spite of / because of / due to** → ตามด้วย **คำนาม หรือ V-ing** เท่านั้น
> - **so** = ผลลัพธ์ · **so that** = จุดประสงค์ · **otherwise** = ไม่อย่างนั้น

## 🏋️ แบบฝึกหัด

> [!question]- 1 เติมคำเชื่อมที่เหมาะสม (and / but / because / although / so / because of)
> 1. I like maths ______ I don't like physics.
> 2. She stayed home ______ she had a headache.
> 3. We arrived late ______ the heavy traffic.
> 4. ______ it was raining, we decided to play football.
> 5. He was very tired, ______ he went to bed early.
>
> > [!success]- เฉลย
> > 1. **but** (ขัดแย้ง)
> > 2. **because** (เหตุ + ประโยค)
> > 3. **because of** (เหตุ + คำนาม the heavy traffic)
> > 4. **Although** (ขัดแย้ง + ประโยค)
> > 5. **so** (ผลลัพธ์ ใส่จุลภาคหน้าได้)

> [!question]- 2 แก้ประโยคต่อไปนี้ให้ถูกต้อง
> 1. Although she studied hard, but she still failed the test.
> 2. Because the weather was bad, so the flight was cancelled.
> 3. Despite he was tired, he finished his homework.
> 4. Unless you don't hurry, you will miss the bus.
>
> > [!success]- เฉลย
> > 1. Although she studied hard, she still failed the test. (ห้ามมี but คู่กับ although)
> > 2. Because the weather was bad, the flight was cancelled. (ห้ามมี so คู่กับ because)
> > 3. Despite **being tired**, he finished his homework. (หรือ Although he was tired, …)
> > 4. Unless you **hurry**, you will miss the bus. (unless = if not จึงไม่ต้องมี don't)

> [!question]- 3 เลือกคำเชื่อมในวงเล็บให้ถูกต้อง พร้อมบอกเหตุผล
> 1. I'll wait here (until / by the time) you come back.
> 2. Take an umbrella (in case / unless) it rains.
> 3. She speaks (not only / both) English but also Chinese.
> 4. He was sick, (therefore / although) he stayed home.
>
> > [!success]- เฉลย
> > 1. **until** = จนกระทั่ง (รอจนกว่าเธอกลับมา)
> > 2. **in case** = เผื่อว่า (เผื่อฝนตก)
> > 3. **not only** เพราะคู่กับ but also
> > 4. **therefore** = ดังนั้น (แสดงผล) · ถ้าใช้ although จะขัดกับความหมาย "ป่วยจึงอยู่บ้าน"

## 🎴 การ์ดทบทวน #flashcards

คำเชื่อม FANBOYS มีอะไรบ้าง::for, and, nor, but, or, yet, so

คำเชื่อมที่ห้ามใช้คู่กับ but คือคำใด::although / though / even though (เลือกใช้อย่างใดอย่างหนึ่งเท่านั้น)

คำเชื่อมที่ห้ามใช้คู่กับ so คือคำใด::because (เพราะว่า) เลือกใช้อย่างเดียว

despite กับ although ใช้ต่างกันอย่างไร::despite + คำนามหรือ V-ing ส่วน although + ประโยคเต็ม

unless แปลว่าอะไรและใช้อย่างไร::แปลว่า "ถ้าไม่" เทียบเท่า if not จึงไม่ต้องใส่ not ซ้ำในประโยค

so กับ so that ต่างกันอย่างไร::so = ดังนั้น (ผลลัพธ์) ส่วน so that = เพื่อว่า (จุดประสงค์)

because กับ because of ต่างกันอย่างไร::because + ประโยค ส่วน because of + คำนามหรือ V-ing

neither … nor ให้ความหมายว่าอย่างไร::ไม่ทั้งสองอย่าง เช่น Neither Tom nor Ann came.
