# งานค้นคว้า — ลิลิตตะเลงพ่าย

> [!abstract] ที่มาของไฟล์นี้
> บันทึกผลการค้นคว้าเบื้องหลังโน้ต [[ภาษาไทย/ลิลิตตะเลงพ่าย]] ทุกข้ออ้างอิงอิงจากแหล่งปฐมภูมิ (ต้นฉบับบทประพันธ์ในวิกิซอร์ซ) และแหล่งรองที่น่าเชื่อถือ (กรมศิลปากร เอกสารวิชาการ ตำรา/สื่อการสอนของครู) — ระเบียบวิธี: สืบค้นด้วยการค้นเว็บและอ่านหน้าเว็บต้นทางโดยตรงทุกข้อ

## จุดที่แหล่งข้อมูลขัดแย้งกัน (และข้อยุติที่ใช้ในโน้ต)

1. **ตำบลตระพังตรุ อยู่จังหวัดใด** — สื่อการสอน "เทียนหนึ่งเล่ม" ระบุเขตจังหวัดกาญจนบุรี แต่ Coggle ระบุจังหวัดสุพรรณบุรี → ในโน้ตจึงระบุเพียง "ตำบลตระพังตรุ" โดยไม่ฟันธงจังหวัด และให้ภาพแผนที่เป็นเส้นทางสัมพัทธ์เท่านั้น
2. **ผู้พระนิพนธ์** — วิกิพีเดียระบุกรมหมื่นภูบาลบริรักษ์ร่วมพระนิพนธ์ด้วย แต่สื่อการสอนและข้อสอบส่วนใหญ่ถือว่าสมเด็จพระมหาสมณเจ้า กรมพระปรมานุชิตชิโนรสเป็นผู้พระนิพนธ์ → ในโน้ตตอบตามข้อสอบว่าเป็นพระนิพนธ์หลักของกรมพระปรมานุชิตชิโนรส และหมายเหตุผู้ร่วมพระนิพนธ์ไว้
3. **พระชนมายุเมื่อสิ้นพระชนม์** — บางแหล่งว่า ๖๒ พรรษา บางแหล่งว่า ๖๔ พรรษา (ประสูติ ๒๓๓๓ สิ้นพระชนม์ ๒๓๙๖) → ในโน้ตระบุเฉพาะปี พ.ศ. เพื่อเลี่ยงข้อขัดแย้ง
4. **จำนวนผู้ตามเสด็จและผู้เสียชีวิต** — "เทียนหนึ่งเล่ม" ระบุผู้ตามเสด็จ ๔ คน เสียชีวิต ๒ คน (นายมหานุภาพ หมื่นภักดีศวร) ซึ่งสอดคล้องกับตัวบทวิกิซอร์ซตอน "สองรอดโดยเสด็จด้าว ศึกสู้เสียสอง" → ใช้ตามนี้

## หมายเหตุระเบียบวิธี

- เดิม skill /research กำหนดให้ส่งงานค้นคว้าไปทำในเบื้องหลังโดยเอเจนต์แยก แต่ในรอบนี้ไม่มีเครื่องมือส่งงานให้เอเจนต์เบื้องหลัง จึงค้นคว้าและตรวจแหล่งต้นทางโดยตรงในเซสชันนี้แทน
