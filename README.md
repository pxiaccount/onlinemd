# 📚 ห้องสมุดโน้ต (onlinemd)

Vault Obsidian รวม**โน้ตการเรียนรู้ภาษาไทย**ทุกวิชา ระดับ ม.5 — จัดทำโดยผู้ช่วย AI (Freebuff) ตามมาตรฐานใน `AGENTS.md`

ทุกโน้ตออกแบบให้ **เข้าใจง่าย เห็นภาพ ทบทวนได้ด้วยตัวเอง**:

- 🖼 **ภาพประกอบ SVG** ในทุกโน้ต — สีสดใส พื้นโปร่งใส ข้อความไทย
- 🧠 คำอธิบายภาษาพูดเข้าใจง่าย + ตัวอย่างใกล้ตัว
- ✏️ ตัวอย่างการคำนวณทีละขั้น พร้อม LaTeX
- 🏋️ แบบฝึกหัดพร้อมเฉลยแบบ**พับซ่อนไว้** (callout)
- 🎴 **การ์ดทบทวน (flashcards)** รองรับปลั๊กอิน Obsidian Spaced Repetition
- 🔗 เชื่อมโยงหัวข้อด้วย wiki-link ทั้ง vault

## 📁 โครงสร้างวิชา

| โฟลเดอร์ | วิชา | ตัวอย่างโน้ต |
|----------|------|-------------|
| `คณิตศาสตร์/` | 📐 คณิตศาสตร์ | ตรีโกณมิติเบื้องต้น, กฎไซน์/โคไซน์, โจทย์ฟังก์ชันตรีโกณมิติ 100 ข้อ |
| `ฟิสิกส์/` | ⚡ ฟิสิกส์ | แสงเชิงคลื่น, การแทรกสอดสลิตคู่, การเลี้ยวเบนเกรตติง, กฎของคูลอมบ์ |
| `เคมี/` | 🧪 เคมี | ปฏิกิริยา redox, ดุลครึ่งปฏิกิริยา, เซลล์กัลวานิก, โจทย์เคมีไฟฟ้า |
| `ชีววิทยา/` | 🌱 ชีววิทยา | การแบ่งตัวแบบคู่ vs การเข้าคู่ของแบคทีเรีย |
| `แผนการเรียน/` | 📅 แผนการเรียน | ตารางทบทวนสอบปลายภาค |

หน้ารวมทั้งหมดอยู่ที่ [[index]] (หรือ `index.md`)

## 🌐 เว็บไซต์

Vault นี้เผยแพร่เป็นเว็บด้วย [Quartz 4](https://quartz.jzhao.xyz/) — โค้ดเว็บอยู่ในโฟลเดอร์ `quartz/`

```bash
# รันเว็บดูในเครื่อง
cd quartz && npx quartz build --serve
```

## 🤖 การใช้กับผู้ช่วย AI

เปิดโฟลเดอร์นี้ใน [Freebuff](https://freebuff.com) แล้วสั่งสร้างโน้ตหัวข้อใหม่ได้เลย เช่น

> "สร้างโน้ตเรื่อง กฎของเลนซ์ ให้หน่อย"

ผู้ช่วยจะสร้างโน้ตตามเทมเพลตมาตรฐาน (SVG + callouts + แบบฝึกหัด + flashcards) วางในโฟลเดอร์วิชาที่ถูกต้อง แล้ว commit & push ให้อัตโนมัติ — รายละเอียดกฎทั้งหมดอยู่ใน `AGENTS.md`
