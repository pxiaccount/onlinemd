# ⚡ ฟิสิกส์

ยินดีต้อนรับสู่โฟลเดอร์ฟิสิกส์ — เลือกหัวข้อด้านล่างเพื่อเริ่มทบทวนได้เลย

## 📚 หัวข้อทั้งหมด

### 🌊 แสงเชิงคลื่น

- 🌊 [[แสงเชิงคลื่น]] — คลื่นแม่เหล็กไฟฟ้า สเปกตรัมแสง และธรรมชาติทวิลักษณ์ของแสง (พื้นฐานก่อนเรียนสลิต)
- ✨ [[การแทรกสอดของแสงผ่านสลิตคู่]] — การทดลองของยัง ริ้วสว่าง–มืด สูตร $d\sin\theta = n\lambda$
- 🕳️ [[การเลี้ยวเบนของแสงผ่านสลิตเดี่ยว]] — ริ้วสว่างกลางกว้างที่สุด สูตร $a\sin\theta = n\lambda$
- 🌈 [[การเลี้ยวเบนของแสงผ่านเกรตติง]] — แยกสเปกตรัมแสง คำนวณเหมือนสลิตคู่ + การนับจำนวนแถบ
- 📄 [[โจทย์ฟิสิกส์-แสงเชิงรังสีและแสงเชิงคลื่น]] — ชุดโจทย์ PDF ภาษาอังกฤษพร้อมเฉลย (เปิดในหน้าเว็บได้)

### 📏 แสงเชิงรังสี

- 📏 [[แสงเชิงรังสี]] — การสะท้อน การหักเห เลนส์ กระจก และกฎสเนลล์

### ⚡ ไฟฟ้าและคลื่น

- 🔌 [[กฎของคูลอมบ์]] — แรงระหว่างประจุไฟฟ้า กลศาสตร์ไฟฟ้าเบื้องต้น
- 🔄 [[การเคลื่อนที่แบบฮาร์มอนิกอย่างง่าย]] — การแกว่ง แอมพลิจูด คาบ ความถี่ (พื้นฐานของคลื่น)
