# เครื่องหมายในแสงเชิงรังสี

> [!abstract] สรุปในหนึ่งบรรทัด
> สูตรแสงเชิงรังสีทุกสูตรใช้ตัวเลขได้ก็ต่อเมื่อ **ใส่เครื่องหมาย (+/−) ถูกก่อนแก้สมการ** — กฎสั้น ๆ มีแค่ 3 ข้อ คือ **จริงเป็นบวก เสมือนเป็นลบ** • **รวมแสงเป็นบวก กระจายแสงเป็นลบ** • **ตั้งขึ้นเป็นบวก กลับหัวเป็นลบ**

$
\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i} \quad,\quad m = -\frac{d_i}{d_o}
$

## 🧠 ทำความเข้าใจ

สูตรแสงเชิงรังสีทุกสูตรเป็นสมการที่มาจาก**การวัดระยะตามแนวแกน** ถ้าวัด "ระยะห่าง" แบบไม่คิดทิศทาง (ค่าบวกอย่างเดียว) สมการจะแยกไม่ออกระหว่างภาพจริงกับภาพเสมือน ระหว่างเลนส์นูนกับเลนส์แว่น — เครื่องหมายคือสิ่งที่บอก**ทิศทาง**ของระยะนั้น ๆ

**หลักการ 3 ข้อของระบบที่ใช้ในโน้ตชุดนี้** (ระบบ "จริงเป็นบวก" หรือ real-is-positive)

1. **วัดจากจุดศูนย์กลาง** — เลนส์วัดจากจุดกึ่งกลางเลนส์ กระจกวัดจากขั้วกระจก (จุดที่แกนตัดผิวกระจก) ระยะทางซ้าย/ขวาของจุดนี้คือเครื่องหมายของ $d_o$ และ $d_i$
2. **ของจริงเป็นบวก ของหลอกเป็นลบ** — ภาพจริง (ฉากรับได้) $d_i$ บวก / ภาพเสมือน (ฉากรับไม่ได้) $d_i$ ลบ
3. **รวมแสงเป็นบวก กระจายแสงเป็นลบ** — เลนส์นูนกับกระจกเว้า $f$ บวก / เลนส์แว่นกับกระจกนูน $f$ ลบ

> [!tip] ประโยชน์ที่ได้
> ทั้งเลนส์และกระจกใช้สูตรเดียวกันคือ $\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i}$ ไม่ต้องจำสองสูตร — จำแค่**เครื่องหมาย**ให้แม่น แล้วคำตอบที่ได้จะบอกชนิดภาพเองอัตโนมัติ (ดูเครื่องหมายของ $d_i$ และ $m$)

## 📋 เครื่องหมายของตัวแปรทุกตัว

| ตัวแปร | ความหมาย | เป็น **บวก** เมื่อ | เป็น **ลบ** เมื่อ |
|---|---|---|---|
| $d_o$ | ระยะวัตถุ | วัตถุจริง อยู่ฝั่งแสงตกกระทบ (ทุกโจทย์ปกติ) | วัตถุเสมือน — ลำแสงที่วิ่งเข้าระบบเป็นลำแสงลู่เข้า (เจอน้อยมาก) |
| $d_i$ | ระยะภาพ | ภาพจริง — เลนส์: อยู่ฝั่งตรงข้ามวัตถุ / กระจก: อยู่ฝั่งเดียวกับวัตถุ | ภาพเสมือน — เลนส์: อยู่ฝั่งเดียวกับวัตถุ / กระจก: อยู่หลังกระจก |
| $f$ | ระยะโฟกัส | เลนส์นูน, กระจกเว้า (รวมแสง) | เลนส์แว่น, กระจกนูน (กระจายแสง) |
| $R$ | รัศมีความโค้ง | กระจกเว้า (จุดศูนย์กลางความโค้งอยู่ฝั่งเดียวกับวัตถุ) | กระจกนูน |
| $R_1, R_2$ | รัศมีความโค้งผิวเลนส์ | ผิวที่จุดศูนย์กลางความโค้งอยู่ฝั่งเดียวกับ**ทางที่แสงออก** | ผิวที่จุดศูนย์กลางความโค้งอยู่ฝั่งเดียวกับ**ทางที่แสงเข้า** |
| $h_o$ | ความสูงวัตถุ | ชี้ขึ้นเหนือแกนมุขสำคัญ (เกือบทุกโจทย์) | ชี้ลงใต้แกน (เจอน้อยมาก) |
| $h_i,\ m$ | ความสูงภาพ / อัตราขยาย | ภาพตั้งตรง (upright) | ภาพกลับหัว (inverted) — เกิดกับภาพจริงของเลนส์นูน/กระจกเว้า |
| $P$ | กำลังเลนส์ | เลนส์นูน (ถ้า $f$ หน่วยเมตร) | เลนส์แว่น |
| $n$ | ดัชนีหักเห | บวกเสมอ ($n = c/v \ge 1$) | ไม่มีค่าลบ |
| $\theta$ | มุมตกกระทบ/สะท้อน/หักเห | บวกเสมอ วัดจาก**เส้นตั้งฉาก** $0°–90°$ | ไม่มีค่าลบ (ถ้าแก้สมการแล้วได้ค่าใช้ไม่ได้ = ไม่มีคำตอบจริง) |
| $\lambda, c, v$ | ความยาวคลื่น, อัตราเร็วแสง | บวกเสมอ | ไม่มีค่าลบ |

> [!info] ภาพจริงของกระจกอยู่ฝั่งไหน?
> ถ้าถามว่า "ทำไมภาพจริงของกระจกอยู่ฝั่งวัตถุ แต่ของเลนส์อยู่ฝั่งตรงข้าม" — เพราะกระจก**สะท้อน**แสงกลับมาทางเดิม ส่วนเลนส์**ทะลุผ่าน**ไปอีกฝั่ง ภาพจริงคือจุดที่รังสีจริงตัดกันจริง ๆ จึงต้องอยู่ฝั่งที่รังสีเดินไปถึง

## 🧮 ใส่เครื่องหมายในแต่ละสูตรอย่างไร

### 1) สูตรเลนส์/กระจก (สูตรหลัก)

$
\frac{1}{f} = \frac{1}{d_o} + \frac{1}{d_i}
$

- เติมเครื่องหมายให้ $f$ และ $d_o$ **ก่อน** แล้วค่อยแก้หา $d_i$
- ถ้า $d_i$ ออกมาเป็นค่าลบ = ภาพเสมือน อยู่ฝั่งเดียวกับวัตถุ (ไม่ต้องแปลกใจ ไม่ใช่คำตอบผิด)
- จัดรูปที่ใช้บ่อย: $d_i = \dfrac{1}{\frac{1}{f} - \frac{1}{d_o}} = \dfrac{f\,d_o}{d_o - f}$

### 2) อัตราขยาย

$
m = \frac{h_i}{h_o} = -\frac{d_i}{d_o}
$

- เครื่องหมายของ $m$ บอกว่าภาพ**ตั้งขึ้น (+) หรือกลับหัว (−)**
- ขนาด $|m|$ บอกว่า**ขยาย** ($>1$) หรือ**หด** ($<1$)
- ภาพจริงทุกกรณีของเลนส์เดี่ยว/กระจกเดี่ยว → $m$ ติดลบ ; ภาพเสมือน → $m$ เป็นบวก

### 3) ระยะโฟกัสของกระจก

$
f = \frac{R}{2}
$

$f$ มีเครื่องหมาย**ตาม $R$ เสมอ** — กระจกเว้า $R$ บวก จึงได้ $f$ บวก ; กระจกนูน $R$ ลบ ได้ $f$ ลบ

### 4) สูตรเลนส์บาง (เลนส์ประดิษฐ์)

$
\frac{1}{f} = (n - 1)\left(\frac{1}{R_1} - \frac{1}{R_2}\right)
$

- เลนส์นูนสองด้าน: $R_1 = +R$ และ $R_2 = -R$ → ได้ $\frac{1}{f} = \frac{2(n-1)}{R} > 0$
- ตัวที่พลาดบ่อยสุดคือ **ลืมใส่เครื่องหมายลบหน้า $R_2$** แล้วคำตอบกลายเป็น $f$ อนันต์ (แบน)

### 5) กำลังเลนส์และการรวมเลนส์

$
P = \frac{1}{f} \quad,\quad P_{\text{total}} = P_1 + P_2 + \dots
$

$f$ ต้องแปลงเป็นเมตรก่อน (หน่วยไดออปเตอร์, D) — เลนส์นูน $P$ บวก, เลนส์แว่น $P$ ลบ ; รวมกันแบบบวก/ลบตรง ๆ (กำลังรวม $P_{\text{total}}$)

### 6) กฎของสเนลล์และมุมวิกฤต — ไม่มีเครื่องหมาย แต่มีเงื่อนไข

$
n_1\sin\theta_1 = n_2\sin\theta_2 \quad,\quad \sin\theta_c = \frac{n_2}{n_1}
$

- ทุกอย่างเป็นบวกเสมอ วัดมุมจากเส้นตั้งฉาก ; $\theta_2$ ต้องมีค่าได้ ($\sin\theta_2 \le 1$) ไม่งั้นเกิดการสะท้อนกลับทั้งหมด
- ใช้ $\sin\theta_c$ ได้เฉพาะเมื่อ $n_1 > n_2$ (จากตัวกลางแน่นไปบาง)

### 7) ปริซึม — เลขบวกทั้งหมด

$
A = r_1 + r_2 \quad,\quad \delta = (i_1 + i_2) - A \quad,\quad n = \frac{\sin\left(\frac{A + \delta_m}{2}\right)}{\sin\left(\frac{A}{2}\right)}
$

มุมในปริซึมไม่ต้องใช้เครื่องหมายลบเลย เพราะนิยามให้เป็นขนาดของมุมบวกทั้งสิ้น

## ✏️ ตัวอย่างการคำนวณ

**ตัวอย่าง 1 (เลนส์นูน — ภาพเสมือน):** วัตถุอยู่หน้าเลนส์นูน $f = 15$ ซม. เป็นระยะ $10$ ซม. จงหาระยะภาพและอัตราขยาย

$
\begin{aligned}
\frac{1}{d_i} &= \frac{1}{f} - \frac{1}{d_o} = \frac{1}{15} - \frac{1}{10} = \frac{2-3}{30} = -\frac{1}{30} \\
d_i &= -30
\end{aligned}
$

($f = +15$ และ $d_o = +10$ ซม. เป็นบวกทั้งคู่)

$
m = -\frac{d_i}{d_o} = -\frac{-30}{10} = +3
$

**สรุปเครื่องหมาย:** $d_i$ ลบ → ภาพเสมือนอยู่ฝั่งเดียวกับวัตถุ ; $m$ บวก → ภาพตั้งตรง ; $|m| = 3$ → ขยาย 3 เท่า — ตรงกับคุณสมบัติของแว่นขยาย (วัตถุอยู่ในระยะ $f$)

**ตัวอย่าง 2 (กระจกนูน — ภาพเสมือนเสมอ):** กระจกนูน $f = -15$ ซม. วัตถุห่าง $30$ ซม. จงหาระยะภาพ

$
\begin{aligned}
\frac{1}{d_i} &= \frac{1}{f} - \frac{1}{d_o} = -\frac{1}{15} - \frac{1}{30} = \frac{-2-1}{30} = -\frac{1}{10} \\
d_i &= -10
\end{aligned}
$

$
m = -\frac{d_i}{d_o} = -\frac{-10}{30} = +\frac{1}{3}
$

**สรุปเครื่องหมาย:** $f$ ลบ (กระจายแสง) → $d_i$ ลบ (ภาพเสมือนหลังกระจก) → $m$ บวก (ตั้งตรง) และหดเหลือ $\frac{1}{3}$ เท่า — ตรงตามทฤษฎีที่ว่ากระจกนูนให้ภาพเสมือน ตั้งตรง หดเสมอ

**ตัวอย่าง 3 (กระจกเว้า — ตรวจด้วย $f = R/2$):** กระจกเว้า $R = 40$ ซม. วางวัตถุห่าง $15$ ซม.

$
f = +\frac{40}{2} = +20
$

$
\begin{aligned}
\frac{1}{d_i} &= \frac{1}{20} - \frac{1}{15} = \frac{3-4}{60} = -\frac{1}{60} \\
d_i &= -60
\end{aligned}
$

$
m = -\frac{-60}{15} = +4
$

วัตถุอยู่ในระยะ $f$ พอดี (15 < 20) จึงได้ภาพเสมือน ตั้งตรง ขยาย 4 เท่า อยู่หลังกระจก — เหมือนที่เห็นในกระจกโกนหนวด

> [!tip] เช็กคำตอบ 3 วินาที
> 1. $d_i$ บวก → ภาพจริง (กลับหัว $m$ ต้องลบ) • $d_i$ ลบ → ภาพเสมือน ($m$ ต้องบวก)
> 2. ถ้าได้ภาพจริงแต่ $m$ เป็นบวก → ใส่เครื่องหมายผิดแน่นอน
> 3. ถ้า $d_o > 2f$ ของเลนส์นูน ต้องได้ภาพจริงหด ($0 < |m| < 1$) — ใช้เทียบคำตอบได้ทันที

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **ผสมสองระบบเครื่องหมายเข้าด้วยกัน** — โน้ตชุดนี้ใช้ระบบ "จริงเป็นบวก" ส่วนตำราอังกฤษ/อินเดีย (New Cartesian) นับทิศแสงตกกระทบเป็นบวก แล้วใช้ $\frac{1}{v} + \frac{1}{u} = \frac{1}{f}$ กับ**กระจก** แต่ $\frac{1}{v} - \frac{1}{u} = \frac{1}{f}$ กับ**เลนส์** (พร้อม $m = -\frac{v}{u}$ สำหรับกระจก และ $m = \frac{v}{u}$ สำหรับเลนส์) — ระบบนี้ตัวเลขเครื่องหมายจะกลับกับโน้ตนี้ทั้งหมด ห้ามใช้สลับกันกลางโจทย์
> 2. **ไม่ติดลบ $f$ ของกระจกนูน/เลนส์แว่น** — ทำให้ได้ภาพจริงกลับหัวทั้งที่ความจริงต้องเป็นภาพเสมือน
> 3. **วัดมุมจากผิวสะท้อน** — มุมทุกตัวในกฎสเนลล์ต้องวัดจาก**เส้นตั้งฉาก (normal)**
> 4. **ลืมเครื่องหมายในสูตรเลนส์บาง** — ผิวด้านหลัง ($R_2$) ของเลนส์นูนต้องเป็นลบ
> 5. **เอาเลขระยะทางดิบใส่หน่วยโดยไม่ดูว่าเป็นบวกหรือลบ** — ระยะที่โจทย์ให้มาเป็น "ขนาด" ต้องแปลงเป็นเครื่องหมายให้ถูกก่อนแทนลงสูตร
> 6. **แปลเครื่องหมายเป็นคำตอบผิด** — $d_i$ ลบไม่ใช่ "ระยะติดลบที่เป็นไปไม่ได้" แต่หมายถึงภาพอยู่ฝั่งตรงข้ามกับที่คาด (ฝั่งวัตถุ)

## 🏋️ แบบฝึกหัด

> [!question]- ข้อ 1: เลนส์แว่น (diverging) มี $f = -20$ ซม. วางวัตถุห่าง $30$ ซม. จงหาระยะภาพและอัตราขยาย พร้อมบอกชนิดภาพ
> > [!success]- เฉลย
> > เติมเครื่องหมาย: $f = -20$, $d_o = +30$ (ซม.)
> >
> > $
> > \frac{1}{d_i} = \frac{1}{-20} - \frac{1}{30} = \frac{-3-2}{60} = -\frac{5}{60} \Rightarrow d_i = -12
> > $
> >
> > $
> > m = -\frac{d_i}{d_o} = -\frac{-12}{30} = +0.4
> > $
> >
> > ภาพ**เสมือน** ($d_i$ ลบ) **ตั้งตรง** ($m$ บวก) **หดเหลือ 0.4 เท่า** อยู่ฝั่งเดียวกับวัตถุ ห่างเลนส์ 12 ซม.

> [!question]- ข้อ 2: กระจกเว้า $R = 40$ ซม. วางวัตถุห่าง $60$ ซม. จงหาระยะภาพ อัตราขยาย และอธิบายว่าเครื่องหมายบอกอะไรบ้าง
> > [!success]- เฉลย
> > $f = +\frac{R}{2} = +20$ ซม. และ $d_o = +60$ ซม.
> >
> > $
> > \frac{1}{d_i} = \frac{1}{20} - \frac{1}{60} = \frac{3-1}{60} = \frac{2}{60} \Rightarrow d_i = +30
> > $
> >
> > $
> > m = -\frac{30}{60} = -0.5
> > $
> >
> > $d_i$ บวก → **ภาพจริง** อยู่หน้ากระจกฝั่งเดียวกับวัตถุ ห่าง 30 ซม. ; $m$ ลบ → **ภาพกลับหัว** และหดครึ่งหนึ่ง (สูงเป็นครึ่งของวัตถุ) — สอดคล้องกับวัตถุอยู่ไกลกว่า $2f$ (60 > 40) ที่ต้องได้ภาพจริงกลับหัวหด

> [!question]- ข้อ 3: กำหนดโจทย์ว่า "วัตถุสูง $2$ ซม. วางหน้าเลนส์นูน $f = 10$ ซม. ห่าง $5$ ซม." โดยยังไม่ต้องคำนวณ จงระบุว่า $d_o$, $f$, และ $d_i$, $m$, $h_i$ ควรมีเครื่องหมายใด พร้อมเหตุผล
> > [!success]- เฉลย
> > - $d_o = +5$ ซม. — วัตถุจริง อยู่ฝั่งแสงตกกระทบ (เป็นบวกเสมอในโจทย์ปกติ)
> > - $f = +10$ ซม. — เลนส์นูน รวมแสง จึงเป็นบวก
> > - $d_i$ ควรเป็น**ลบ** — เพราะ $d_o < f$ (5 < 10) วัตถุอยู่ในระยะโฟกัส จึงต้องได้ภาพเสมือนอยู่ฝั่งเดียวกับวัตถุ
> > - $m$ ควรเป็น**บวก** — ภาพเสมือนตั้งตรง (และเป็นบวกที่มากกว่า 1 คือขยาย)
> > - $h_i$ มีเครื่องหมาย**บวก** — สูง $|m| \times 2$ ซม. และชี้ขึ้นเหมือนวัตถุ
> >
> > ตรวจกับสูตรได้จริง: $\frac{1}{d_i} = \frac{1}{10} - \frac{1}{5} = -\frac{1}{10} \Rightarrow d_i = -10$ ซม. และ $m = -\frac{-10}{5} = +2$ (ภาพเสมือน ตั้งตรง ขยาย 2 เท่า สูง 4 ซม.)

## 🎴 การ์ดทบทวน #flashcards

เครื่องหมายของ $d_i$ บอกอะไร?::บอกชนิดภาพ — บวก = ภาพจริง, ลบ = ภาพเสมือน (จริงเป็นบวก เสมือนเป็นลบ)

เลนส์นูนกับกระจกเว้า $f$ มีเครื่องหมายใด?::เป็นบวกทั้งคู่ เพราะรวมแสง — ส่วนเลนส์แว่นกับกระจกนูน $f$ เป็นลบ (กระจายแสง)

$m$ ติดลบหมายถึงอะไร?::ภาพกลับหัว (inverted) — มักเกิดกับภาพจริงของเลนส์นูน/กระจกเว้า

ภาพจริงของกระจกเกิดฝั่งไหน?::ฝั่งเดียวกับวัตถุ (หน้ากระจก) — ส่วนภาพเสมือนเกิดหลังกระจก เพราะกระจกสะท้อนแสงกลับมาทางเดิม

ตัวแปรใดในแสงเชิงรังสีที่ไม่มีวันติดลบ?::$n$, $\theta$, $\lambda$, $c$, $v$ — เช่น $n = \frac{c}{v} \ge 1$ และมุมทุกตัววัดจากเส้นตั้งฉากเป็นค่าบวก

ระบบ Cartesian (ใหม่) ต่างจากระบบจริงเป็นบวกตรงไหน?::กระจกใช้ $\frac{1}{v} + \frac{1}{u} = \frac{1}{f}$ แต่เลนส์ใช้ $\frac{1}{v} - \frac{1}{u} = \frac{1}{f}$ — และ $u$ ของวัตถุจริงเป็นลบเสมอ (ห้ามผสมสองระบบ)

สูตรเลนส์บางใส่เครื่องหมาย $R_2$ อย่างไร?::ผิวหลังของเลนส์นูนมี $R_2$ เป็นลบ: $\frac{1}{f} = (n-1)\left(\frac{1}{R_1} - \frac{1}{R_2}\right)$

- [[แสงเชิงคลื่น]] — มุมมองคลื่นของแสง ใช้เมื่อวัตถุหรือช่องแคบมีขนาดใกล้ความยาวคลื่น
