# ประชากรและการตั้งถิ่นฐาน

> [!abstract] สรุปในหนึ่งบรรทัด
> ประชากรกระจายตัวตาม**ความอุดมสมบูรณ์ของพื้นที่** (ที่ราบลุ่มน้ำ = หนาแน่น / ภูเขา–ทะเลทราย = ห่างเหิน) โลกและไทยกำลังเข้าสู่**สังคมสูงวัย** และมีการย้ายถิ่นจากชนบทสู่เมืองมากขึ้นเรื่อย ๆ

## 🧠 ทำความเข้าใจ

**ประชากร** = จำนวนคนทั้งหมดในพื้นที่หนึ่ง ในช่วงเวลาหนึ่ง

### 1. การกระจายและความหนาแน่นของประชากร

| ปัจจัย | หนาแน่นสูง | หนาแน่นต่ำ |
|--------|-----------|-----------|
| **ภูมิประเทศ** (กายภาพ) | ที่ราบลุ่มแม่น้ำอุดมสมบูรณ์ | ที่สูง/ภูเขา (หิมาลัย) ทะเลทราย |
| **ทรัพยากร** | มีป่าไม้ น้ำ ดิน แหล่งอาหาร | ทรัพยากร/อาหารน้อย |
| **ภูมิอากาศ** | อบอุ่น ฝนเพียงพอทำเกษตร | ร้อนจัด แห้งแล้ง หรือหนาวจัด |
| **การเมือง** (มนุษย์) | เสถียรภาพ มั่นคง | ขัดแย้ง สงคราม → ย้ายถิ่น |
| **เศรษฐกิจ** (มนุษย์) | โอกาสทำงานสูง (เมืองใหญ่) | โอกาสจำกัด |

### 2. ประชากรไทย

- พ.ศ. 2567 = **65,951,210 คน** กำลังเข้าสู่ **"สังคมสูงวัยเต็มรูปแบบ"** (ผู้สูงอายุเพิ่ม เกิดน้อยลง → ระยะยาวประชากรลด แรงงานหดตัว)
- พีระมิดประชากร 3 แบบ:
  1. **ฐานกว้าง**: เด็กมาก เกิดสูงตายสูง — อัฟกานิสถาน โซมาเลีย ไนเจอร์
  2. **คงที่**: ทุกช่วงวัยใกล้เคียง — สหรัฐฯ ออสเตรเลีย
  3. **ฐานแคบ**: เด็กน้อย สูงวัยมาก เกิดต่ำ — จีน เยอรมนี สวีเดน สิงคโปร์ ญี่ปุ่น อิตาลี
- ไทย: พ.ศ. 2503 ผู้สูงอายุ 65+ ไม่ถึง 3% → พ.ศ. 2557 = **14.9%** → พ.ศ. 2569 ภาระพึ่งพิงผู้สูงอายุสูงขึ้นต่อเนื่อง
- โลก: ผู้สูงอายุ 60+ จาก 901 ล้านคน (2558, 12.3%) → 1,402 ล้าน (2573, 16.5%) → 2,092 ล้าน (2593, 21.5%) — ยุโรปมีผู้สูงอายุมากที่สุด อายุเฉลี่ยโลกเพิ่มขึ้นอย่างน้อย 9 ปี

### 3. การเปลี่ยนแปลงของประชากร

**อัตราเกิด**:
- อัตราเกิดอย่างหยาบ (crude birth rate) = จำนวนเกิดมีชีพต่อประชากร 1,000 คนต่อปี
- อัตราเจริญพันธุ์รวม (total fertility rate) = จำนวนบุตรเฉลี่ยที่สตรี 1 คนจะมี
- โลกลดจาก 20–21 คน/1,000 (พ.ศ. 2549) → 16–17 คน/1,000 (พ.ศ. 2569)

**อัตราตาย**: อัตราตายอย่างหยาบ (crude death rate) = ตายต่อ 1,000 คน; **อายุคาดเฉลี่ย** (life expectancy) ยืนขึ้นจากสาธารณสุข–เทคโนโลยีการแพทย์

**การย้ายถิ่น**:
| ประเภท | ลักษณะ |
|--------|--------|
| สมัครใจ (voluntary) | หวังชีวิต–เศรษฐกิจดีกว่าที่ปลายทาง |
| ถูกบังคับ (forced) | ถูกข่มขู่ ชีวิตถูกคุกคาม เช่น สงคราม–โรคระบาด–ภัยธรรมชาติ |

- ปัจจัยผลัก–ดึง: สภาพแวดล้อม (ราบลุ่มอุดม) เศรษฐกิจ (อาชีพหลากหลาย) ความปลอดภัย
- สถานการณ์: ในประเทศ = ชนบท → เมือง (ราคาพืชผลตก) / ระหว่างประเทศ = สงครามรัสเซีย–ยูเครน (2565) ผู้ลี้ภัยกว่า **8.2 ล้านคน** (รัสเซีย ~2.9 ล้าน โปแลนด์ ~1.6 ล้าน) / ข้ามทวีป = แรงงานเอเชีย–แอฟริกา → ยุโรป–อเมริกาเหนือ

### 4. การตั้งถิ่นฐาน

**ขนาด**: กลุ่มบ้าน (hamlet, <100 คน) → หมู่บ้าน (village, 100–1,000) → เมือง (town, 1,000–100,000) → เมืองใหญ่ (city, 100,000–300,000) → มหานคร (metropolis, ศูนย์กลางเศรษฐกิจ–ปกครอง) → อภิมหานคร (megalopolis, หลายมหานครติดกัน)

**เมืองกับชนบท**:
| | ชนบท | เมือง |
|--|------|-------|
| สิ่งแวดล้อม | พึ่งธรรมชาติ | มลพิษจากอุตสาหกรรม–จราจร |
| การตั้งถิ่นฐาน | กระจัดกระจาย ตามแหล่งน้ำ | วางผังรองรับประชากรเพิ่ม |
| อาชีพ | เกษตร เลี้ยงสัตว์ ประมง | ค้าขาย บริการ หลากหลาย |

**ชนบทของโลก 4 แบบ**: โดดเดี่ยว (dispersed — บ้านอยู่ในแปลงเกษตร) / รวมกลุ่ม (nucleated — รวมที่วัด โรงเรียน ตลาด) / แนวยาว (linear — ตามถนนหรือแม่น้ำ) / ตารางกริด (grid — วางผังสี่เหลี่ยม)

**ไทย**: ตั้งถิ่นฐานตามปัจจัยพื้นที่–ทรัพยากร ใกล้แหล่งน้ำเพื่อเพาะปลูก / กรุงเทพฯ คือมหานคร + **เมืองโตเดี่ยว (primate city)** ประชากร ~5.6 ล้านคน รวมศูนย์การพัฒนาไว้ที่เดียว

**การใช้ที่ดินในเมือง**: ศูนย์กลางธุรกิจ (ใจกลางเมือง) / ที่อยู่อาศัยรายได้น้อย (แออัด ใกล้ใจกลาง) / รายได้ปานกลาง / รายได้สูง (ชานเมือง ที่ดินถูก ไม่แออัด) / อุตสาหกรรม (หนักอยู่ชานเมือง) / เขตสถาบัน–ราชการ

**ปัญหาเมือง**: ขยายตัวกลืนชานเมือง / ชุมชนแออัด (ผิดกฎหมาย ไม่ถูกสุขลักษณะ อาชญากรรม–ยาเสพติด) / สิ่งแวดล้อมเสื่อม (น้ำเน่าเสีย) / ความไม่ปลอดภัย / ครอบครัวเปลี่ยน (โสดมากขึ้น แต่งงานช้า ลูกน้อย → สูงวัยมากขึ้น)

## ✏️ ตัวอย่างการวิเคราะห์

ทำไมริมแม่น้ำเจ้าพระยาจึงมีประชากรหนาแน่นกว่าบนภูเขาเหนือของไทย?

1. **ภูมิประเทศ**: ที่ราบลุ่มแม่น้ำราบเรียบ สร้างบ้านเรือน–ทำนาได้ง่าย ภูเขาลาดชันทำเกษตรยาก
2. **ทรัพยากร**: น้ำอุดม ดินตะกอนใหม่ ปลา ค้าขายทางน้ำสะดวก
3. **ภูมิอากาศ**: พอเหมาะต่อข้าว (มรสุม)
4. **เศรษฐกิจ–การเมือง**: ชุมชนเก่าแก่เป็นศูนย์กลางปกครอง ค้าขาย มีงานมาก → ดึงดูดคนย้ายเข้า
→ ปัจจัยกายภาพ + มนุษย์ทำงานร่วมกัน

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **อัตราเกิดอย่างหยาบ** วัดต่อ 1,000 คน **ไม่ใช่** เปอร์เซ็นต์ — อย่าเขียน "อัตราเกิด 16.5%"
> 2. พีระมิด**ฐานแคบ** (จีน เยอรมนี) หมายถึงประชากรวัยเด็ก**ลดลง** ไม่ใช่ประชากรรวมลดทันที
> 3. การย้ายถิ่นแบบ**ถูกบังคับ** ไม่ใช่แค่ถูกใครสั่ง — รวมถึงหนีสงคราม ภัยธรรมชาติ โรคระบาดด้วย
> 4. **มหานคร ≠ อภิมหานคร** — มหานครคือเมืองศูนย์กลางหนึ่งเมือง / อภิมหานครคือหลายมหานครติดต่อกันเป็นแนว
> 5. เมืองโตเดี่ยว (primate city) เน้นความ**รวมศูนย์เกินส่วน** (กรุงเทพฯ ใหญ่กว่าเมืองรองหลายเท่า) ไม่ใช่แค่ "เมืองใหญ่"

## 🏋️ แบบฝึกหัด

> [!question]- 1 พีระมิดประชากรแบบใดสะท้อนสังคมสูงวัย ลักษณะเป็นอย่างไร ยกตัวอย่างประเทศ
> > [!success]- เฉลย
> > **พีระมิดฐานแคบ (ยอดกว้าง)** — สัดส่วนประชากรวัยเด็กลดลง ผู้สูงอายุมาก อัตราเกิดต่ำ อัตราตายลดลง คนอายุยืนขึ้น
> > ตัวอย่าง: จีน เยอรมนี สวีเดน สิงคโปร์ ญี่ปุ่น อิตาลี (และปัจจุบันไทยก็เข้าใกล้/เข้าสู่สังคมสูงวัยเต็มรูปแบบแล้ว)

> [!question]- 2 สงครามรัสเซีย–ยูเครนทำให้เกิดผู้ลี้ภัยกว่า 8.2 ล้านคน การย้ายถิ่นนี้จัดเป็นประเภทใด เพราะเหตุใด และต่างจากแรงงานเอเชียไปทำงานยุโรปอย่างไร
> > [!success]- เฉลย
> > เป็น**การย้ายถิ่นโดยถูกบังคับ (forced migration)** — เพราะผู้คนต้องหนีความขัดแย้ง/สงครามที่คุกคามชีวิตและสุขภาวะ ไม่ได้ย้ายด้วยความสมัครใจ
> > ต่างจากแรงงานเอเชีย→ยุโรป ซึ่งเป็น**การย้ายถิ่นแบบสมัครใจ (voluntary)** — ย้ายเพื่อแสวงหาชีวิตและรายได้ที่ดีกว่า

> [!question]- 3 หมู่บ้านหลังเขาแห่งหนึ่งเริ่มมีคนย้ายเข้าเมืองมากขึ้น วิเคราะห์ผลกระทบทั้งหมู่บ้านและเมืองปลายทาง
> > [!success]- เฉลย
> > **หมู่บ้าน (แหล่งเดิม)**: แรงงานภาคเกษตรลด ที่ดินร้าง คนเหลือผู้สูงอายุ รายได้ครอบครัวอาจดีขึ้นจากเงินที่ลูกส่งกลับ
> > **เมือง (ปลายทาง)**: ประชากรเพิ่ม → ขยายตัวกลืนชานเมือง เกิดชุมชนแออัด มลพิษเพิ่ม แข่งขันงานแรงงานฝีมือต่ำ แต่ได้แรงงานมาเสริมภาคบริการ–อุตสาหกรรม
> > สะท้อนกระบวนการ "การย้ายถิ่นจากชนบทสู่เมือง" ที่เป็นแนวโน้มหลักของโลก

อัตราเกิดอย่างหยาบ (crude birth rate) คือ?::จำนวนเกิดมีชีพในปีหนึ่งต่อประชากร 1,000 คน เมื่อกลางปีนั้น

การย้ายถิ่นสมัครใจกับถูกบังคับต่างกันอย่างไร?::สมัครใจ = หวังชีวิต/เศรษฐกิจดีกว่า / ถูกบังคับ = ถูกข่มขู่หรือชีวิตถูกคุกคาม เช่น หนีสงคราม ภัยธรรมชาติ

ขนาดการตั้งถิ่นฐานเรียงจากเล็กไปใหญ่?::กลุ่มบ้าน (<100 คน) → หมู่บ้าน (100–1,000) → เมือง (1,000–100,000) → เมืองใหญ่ (100,000–300,000) → มหานคร → อภิมหานคร

เมืองโตเดี่ยว (primate city) คือ?::เมืองที่รวมการพัฒนาและประชากรไว้ที่เมืองเดียวเกินส่วน เช่น กรุงเทพฯ (~5.6 ล้านคน)

การตั้งถิ่นฐานชนบท 4 แบบ?::โดดเดี่ยว (dispersed) รวมกลุ่ม (nucleated) แนวยาว (linear) ตารางกริด (grid)

## 🔗 หัวข้อที่เกี่ยวข้อง

- [[เกษตรกรรมและกิจกรรมทางเศรษฐกิจของโลก]] — อาชีพและเศรษฐกิจเป็นปัจจัยดึงดูดประชากร
- [[ภัยพิบัติทางธรรมชาติ]] — ภัยพิบัติเป็นปัจจัยผลักดันการย้ายถิ่นแบบถูกบังคับ
- [[ชีวนิเวศของโลก]] — สภาพแวดล้อมกำหนดทั้งถิ่นที่อยู่ของสิ่งมีชีวิตและการตั้งถิ่นฐานของคน
- [[โจทย์สังคมศึกษา ชีวนิเวศ เศรษฐกิจ และประชากร]] — โจทย์อัตนัยข้อ 9–12 ว่าด้วยความหนาแน่น พีระมิดประชากร และการย้ายถิ่น
