# อุทกภัย ไฟป่า และภัยแล้ง

> [!abstract] สรุปในหนึ่งบรรทัด
> สามภัยที่คนไทยเจอบ่อยที่สุด — **อุทกภัย** (น้ำท่วมจากฝนตกหนัก + มนุษย์บุกรุก) **ไฟป่า** (สามเหลี่ยมไฟ: เชื้อเพลิง + ออกซิเจน + ความร้อน) **ภัยแล้ง** (ฝนทิ้งช่วงนานจนขาดน้ำ) — ล้วนจัดการได้ด้วยมาตรการ ป้องกัน และการปฏิบัติตนก่อน–ขณะ–หลังภัย

## 🧠 ทำความเข้าใจ

### 1. อุทกภัย (flood)

น้ำในลำน้ำ/แอ่งน้ำหรือน้ำท่วมฉับพลันเป็นระยะเวลาสั้น จาก**ฝนตกหนักหรือหิมะละลาย**

**ประเภท 3 แบบ**:
1. **น้ำท่วมฉับพลัน / น้ำป่าไหลหลาก** — ฝนตกหนักในบริเวณที่ลาดชัน
2. **น้ำท่วมขัง** — น้ำสะสมจำนวนมากไหลบ่าจากที่สูงสู่ที่ต่ำ ท่วมบ้านเรือน
3. **น้ำล้นตลิ่ง** — ฝนตกหนักต่อเนื่อง น้ำไหลลงลำน้ำจนเอ่อล้น

**สาเหตุ**:
- ธรรมชาติ: ฝนตกหนักจากพายุฝนฟ้าคะนอง / พายุหมุนเขตร้อน / ลมมรสุม / น้ำทะเลหนุน
- มนุษย์: ตัดไม้ทำลายป่า / ขยายเมืองรุกล้ำที่ลุ่ม / สร้างสิ่งก่อสร้างกีดขวางทางน้ำ / จัดการน้ำไม่มีประสิทธิภาพ

**ภัยตามมา**: บ้านเรือนเสียหาย แผ่นดินถล่ม (ที่ลาดชัน) ไฟฟ้าดูด–รั่ว สัตว์ร้าย มลพิษน้ำ (น้ำกัดเท้า อหิวาตกโรค) เศรษฐกิจตัดขาด

**การจัดการ**:
- มาตรการ: สร้างเขื่อน–พนังกั้นน้ำ (แบบมีสิ่งก่อสร้าง) ปรับรูปแบบการใช้ที่ดิน (ไม่ใช้สิ่งก่อสร้าง)
- ป้องกัน: พยากรณ์–เตือนภัย / ให้ความรู้ประชาชน / ไม่บุกรุกทำลายป่า
- ปฏิบัติตน: ก่อน — ติดตามรายงาน วางแผนอพยพ ขุดลอกแหล่งน้ำตื้นเขิน / ขณะ — อยู่ที่สูง ตัดสะพานไฟ ไม่ขับรถในกระแสน้ำ ไม่เล่นน้ำ ระวังสัตว์มีพิษ / หลัง — ทำความสะอาด ซ่อมบ้าน ฝังซากสัตว์ สงเคราะห์ผู้ประสบภัย

### 2. ไฟป่า (wildfire)

ไฟเผาไหม้เชื้อเพลิงในป่า (เศษไม้ หญ้า วัชพืช ไม้พุ่ม ต้นไม้) แล้ว**ลุกลามไม่มีขอบเขต**

**สามเหลี่ยมไฟ (fire triangle)**: เชื้อเพลิง + ออกซิเจน + ความร้อน — ครบสามอย่างจึงเกิดไฟได้ (จัดการไฟป่า = ตัดตัวใดตัวหนึ่งออก เช่น ทำแนวกันไฟลดเชื้อเพลิง)

**ประเภท 3 แบบ**:
| แบบ | ไหม้ตรงไหน | จุดเด่น |
|-----|-----------|---------|
| **ไฟเรือนยอด** | ตามเรือนยอดต้นไม้ | มักในป่าสนเขตอบอุ่น รุนแรง–เสียหายสุด |
| **ไฟผิวดิน** | ไม้พุ่ม วัชพืช บนผิวดิน | ลุกลามเร็วตามความหนาแน่นของเชื้อเพลิง |
| **ไฟใต้ดิน** | เชื้อเพลิงทับถมในดิน | เผาช้า ๆ **ไม่มีเปลวไฟให้เห็น** เกิดหลังไฟผิวดิน |

**สาเหตุ**: ธรรมชาติ — ฟ้าผ่า กิ่งไม้เสียดสี ภูเขาไฟปะทุ ภัยแล้ง / มนุษย์ — เผาป่าหาของป่า เผาไร่–เศษพืช ประมาท (จุดไฟพักแรม ทิ้งก้นบุหรี่)

**ภัยตามมา**: หมอกควัน → อากาศเป็นพิษ โรคทางเดินหายใจ / ป่า–พรรณไม้ถูกเผา / หน้าดินเปิดโล่ง ดินเสื่อม / สัตว์ป่าตาย–อพยพ

**การจัดการ**: รวบรวมข้อมูล–เตรียมคนและเครื่องมือ / **จัดการเชื้อเพลิง** (แนวกันไฟ ลดเชื้อเพลิง เผาตามกำหนด) / กำหนดเขตควบคุม / ป้องกัน: ให้ความรู้ ฝึกอบรมดับไฟ / ปฏิบัติตน: ก่อน — เก็บกวาดใบไม้แห้งริมป่า ทำระบบป้องกัน / ขณะ — อพยพใส่หน้ากาก สร้างแนวกันไฟ ระวังสูดควันลมแรง / หลัง — จัดระบบควบคุมด้วยน้ำ เวรยามเฝ้าระวัง

### 3. ภัยแล้ง (drought)

**ฝนตกน้อยกว่าปกติต่อเนื่องเป็นเวลานาน** → ขาดแคลนน้ำอุปโภค–บริโภค–เกษตร ความรุนแรงขึ้นกับความชื้นในอากาศ ระยะเวลา และขนาดพื้นที่

**กระบวนการ**: ฤดูฝนมี "ฝนแล้ง/ฝนทิ้งช่วง" นาน → ฝนเฉลี่ยต่ำกว่าปกติ → นอกเขตชลประทานขาดน้ำ → ดินแห้ง พืชเหี่ยวตาย สัตว์ย้ายหาน้ำ → น้ำใต้ดินลด ต้นไม้ใหญ่เหี่ยว ดินแตกระแหง

**ประเภท 3 แบบ**:
| แบบ | สังเกตจาก |
|-----|-----------|
| **อุตุนิยมวิทยา** | ฝนเฉลี่ยต่ำกว่าค่าเฉลี่ยระยะยาวของพื้นที่ |
| **การเกษตร** | ความชื้นในดินไม่พอให้พืชใช้ → ผลผลิตลด |
| **อุทกวิทยา** | น้ำในแม่น้ำ หนอง บึง อ่างเก็บน้ำ น้ำใต้ดินต่ำกว่าปกติ |

**สาเหตุ**: สภาพอากาศผันแปร ฝนทิ้งช่วง / ร่องมรสุมผิดตำแหน่ง / ขาดแหล่งกักเก็บน้ำ / ตัดไม้ทำลายป่า / ประชากรเพิ่ม ใช้น้ำมาก

**ภัยตามมา**: ขาดแคลนน้ำ / ระบบนิเวศน้ำตาย–สูญพันธุ์ / เกิด**ไฟป่า**ง่าย (ร้อน+แล้ง) / เศรษฐกิจเสียหาย (เกษตร–อุตสาหกรรม)

**การจัดการ**: ชลประทานมีประสิทธิภาพ จัดสรรน้ำเหมาะสม / สร้างแหล่งน้ำขนาดใหญ่ / ระบบเตือนภัยแล้ง (ปฏิทินภัย) / ปฏิบัติตน: ก่อน — เตรียมภาชนะเก็บน้ำ ขุดบ่อ ติดตามอากาศ กำจัดเชื้อเพลิงรอบที่พัก / ขณะ — ใช้น้ำประหยัด (ฝักบัว) ปลูกพืชอายุสั้นใช้น้ำน้อย (แตงโม พืชตระกูลถั่ว) ตรวจท่อรั่ว / หลัง — วางแผนระยะยาว (ฝาย เขื่อน) ลดเรือนกระจก รณรงค์อนุรักษ์น้ำ

> [!tip] เชื่อมโยงสามภัย
> น้ำ–ไฟ–แล้งเกี่ยวเหลื่อมกัน: **ตัดป่า → ภัยแล้งง่าย → แห้งจัด → ไฟป่า → หน้าดินเปิดโล่ง → ฝนตกหนัก → น้ำป่าไหลหลาก + ดินถล่ม** — วงจรเดียวกันทั้งหมด!

## ✏️ ตัวอย่างการวิเคราะห์

จังหวัดเชียงใหม่ปี 2562 เผชิญหมอกควันหนาแน่น — เชื่อมโยงสาเหตุกับผลกระทบ

1. **ต้นเหตุ**: การเผาไร่–เศษพืชเกษตร + ไฟป่าช่วงฤดูแล้ง (ก.พ.–เม.ย.) + ภูมิประเทศแอ่งกระทะกักควัน
2. **เชื้อเพลิงสะสม**: ฤดูแล้งยาวทำใบไม้แห้ง–หญ้าแห้งกลายเป็นเชื้อเพลิงจำนวนมาก (องค์ประกอบที่ 1 ของสามเหลี่ยมไฟ)
3. **ผลตามมา**: PM2.5 สูง → โรคทางเดินหายใจเพิ่ม / หน้าดินเปิดโล่ง / สัตว์ป่าอพยพ
4. **มาตรการที่เหมาะ**: เผาตามกำหนด–ลดเชื้อเพลิงแบบมีแนวกันไฟ, ให้ความรู้ชุมชน, ฝึกอาสาสมัครดับไฟ, ระบบเฝ้าระวังจุดความร้อน

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **ไฟใต้ดิน**ไม่มีเปลวไฟให้เห็น — อย่าคิดว่าไฟดับเพราะ "มองไม่เห็นไฟ" ต้องกำจัดเชื้อเพลิงร้อนในดิน
> 2. **ภัยแล้งวัดที่ปริมาณฝนเทียบค่าเฉลี่ย** ไม่ใช่วัดที่อุณหภูมิ — ปีหนึ่งอาจไม่ร้อนกว่าปีปกติแต่แล้งเพราะฝนทิ้งช่วง
> 3. ภัยแล้งทาง**อุตุนิยมวิทยา ≠ ทางอุทกวิทยา** — อุตุฯ ดูฝน / อุทกฯ ดูระดับน้ำในแหล่งน้ำและน้ำใต้ดิน
> 4. เขื่อนช่วยลดน้ำท่วมได้ แต่ถ้า**จัดการน้ำไม่มีประสิทธิภาพ** เขื่อนก็กลายเป็นสาเหตุ (ปล่อยน้ำผิดเวลา)
> 5. ขณะน้ำท่วม **ห้ามขับรถฝ่ากระแสน้ำ** — น้ำลึกเพียง 30 ซม. ก็ลอยรถได้

## 🏋️ แบบฝึกหัด

> [!question]- 1 นำ "สามเหลี่ยมไฟ" มาอธิบายว่าเหตุใดการทำแนวกันไฟจึงช่วยหยุดไฟป่าได้
> > [!success]- เฉลย
> > ไฟเกิดได้ต้องครบ 3 องค์ประกอบ: **เชื้อเพลิง + ออกซิเจน + ความร้อน**
> > แนวกันไฟคือการ**กำจัดเชื้อเพลิงออกเป็นแนวกว้าง** (ถางใบไม้แห้ง–หญ้าแห้งออก) → ไฟที่ลุกลามมาไม่มีเชื้อเพลิงให้ไหม้ต่อ → ไฟดับเอง ไม่ข้ามไปฝั่งตรงข้ามได้
> > นี่คือการตัดองค์ประกอบหนึ่งของสามเหลี่ยมไฟออก (เช่นเดียวกับราดน้ำ = ตัดความร้อน)

> [!question]- 2 หมู่บ้านนอกเขตชลประทานประสบฝนทิ้งช่วง 4 เดือน บ่อน้ำแห้ง ข้าวตาย จงจำแนกว่าเป็นภัยแล้งแบบใด และเสนอแนวทางรับมือทั้งระยะสั้นและระยะยาว
> > [!success]- เฉลย
> > เป็นภัยแล้งได้หลายแบบพร้อมกัน: **อุตุนิยมวิทยา** (ฝนต่ำกว่าค่าเฉลี่ย) → **การเกษตร** (ดินไม่มีความชื้น ข้าวตาย) → **อุทกวิทยา** (บ่อน้ำแห้ง น้ำใต้ดินลด)
> > ระยะสั้น: ปลูกพืชอายุสั้นใช้น้ำน้อย (แตงโม พืชตระกูลถั่ว) ใช้น้ำอย่างประหยัด เตรียมภาชนะเก็บน้ำ แจกจ่ายน้ำเฉพาะหน้า
> > ระยะยาว: ขุดบ่อ–สร้างฝาย เขื่อน เติมน้ำใต้ดิน ปลูกป่าฟื้นความชุ่มชื้น ทำปฏิทินเตือนภัยแล้ง จัดระบบชลประทานให้ครอบคลุม

> [!question]- 3 เมืองหนึ่งขยายตัวรุกล้ำพื้นที่ลุ่มรับน้ำ พร้อมกับตัดป่าต้นน้ำ 10 ปีต่อมาเกิดน้ำท่วมรุนแรงกว่าเดิม เพราะอะไร
> > [!success]- เฉลย
> > สาเหตุมาจากมนุษย์สองทางผนวกกัน:
> > 1. **รุกล้ำพื้นที่ลุ่ม** — ที่ลุ่มเดิมทำหน้าที่เป็น "ฟองน้ำ" กักเก็บน้ำไหลบ่า พอถูกถมสร้างบ้าน น้ำไม่มีที่ซึม/กักไว้ → ท่วมบ้านเรือนโดยตรง
> > 2. **ตัดป่าต้นน้ำ** — ป่าดูดซับ–ชะลอน้ำฝน พอไม่มีป่า น้ำไหลลงลำน้ำเร็วและมากพร้อมกัน → น้ำล้นตลิ่ง
> > 3. พื้นคอนกรีตเพิ่ม → น้ำซึมลงดินน้อยลง ไหลบ่าเร็วขึ้นอีก
> > → อุทกภัยครั้งใหญ่จึงเป็นผลจาก "สาเหตุจากธรรมชาติ (ฝนตกหนัก) + สาเหตุจากมนุษย์" ร่วมกัน

## 🎴 การ์ดทบทวน #flashcards

อุทกภัย 3 ประเภทคืออะไร?::น้ำท่วมฉับพลัน/น้ำป่าไหลหลาก (ลาดชัน) น้ำท่วมขัง (ไหลบ่ารวมที่ลุ่ม) น้ำล้นตลิ่ง (ฝนตกหนักต่อเนื่อง)

สาเหตุอุทกภัยจากมนุษย์มีอะไรบ้าง?::ตัดไม้ทำลายป่า ขยายเมืองรุกล้ำที่ลุ่ม สร้างสิ่งก่อสร้างกีดขวางทางน้ำ จัดการน้ำไม่มีประสิทธิภาพ

สามเหลี่ยมไฟ (fire triangle) มีอะไรบ้าง?::เชื้อเพลิง + ออกซิเจน + ความร้อน — ครบสามอย่างไฟจึงเกิดและลุกลามได้

ไฟป่า 3 ประเภท แบบไหนรุนแรงสุด?::ไฟเรือนยอด (รุนแรงสุด ไหม้ตามยอดไม้ป่าสน) ไฟผิวดิน (ไหม้ไม้พุ่ม–วัชพืช) ไฟใต้ดิน (เผาช้า ไม่มีเปลวไฟเห็น)

ภัยแล้ง 3 ประเภทแยกกันอย่างไร?::อุตุนิยมวิทยา = ฝนน้อยกว่าค่าเฉลี่ย / การเกษตร = ความชื้นดินไม่พอให้พืชใช้ / อุทกวิทยา = น้ำผิวดิน–น้ำใต้ดินต่ำกว่าปกติ

พืชอะไรปลูกได้ดีในช่วงภัยแล้ง?::พืชอายุสั้นใช้น้ำน้อย เช่น แตงโม พืชตระกูลถั่ว

มาตรการจัดการไฟป่าที่สำคัญที่สุดคืออะไร?::การจัดการเชื้อเพลิง — ทำแนวกันไฟ ลดปริมาณเชื้อเพลิง เผาตามกำหนดในพื้นที่เสี่ยง

ปฏิบัติตนอย่างไรขณะเกิดน้ำท่วม?::อยู่อาคารแข็งแรงที่สูงพ้นน้ำ ตัดสะพานไฟ ไม่ใกล้อุปกรณ์ไฟฟ้า ไม่ขับรถฝ่าน้ำ ไม่เล่นน้ำ ระวังสัตว์มีพิษ
