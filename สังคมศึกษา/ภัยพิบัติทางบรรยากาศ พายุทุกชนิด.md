# ภัยพิบัติทางบรรยากาศ: พายุทุกชนิด

> [!abstract] สรุปในหนึ่งบรรทัด
> ภัยทางอากาศมี 3 ตระกูลใหญ่ — **พายุฝนฟ้าคะนอง** (เมฆแนวดิ่ง 3 ขั้น: ก่อตัว–เต็มที่–สลาย) **พายุหมุนเขตร้อน** (เกิดเหนือน้ำทะเล 27°C ขึ้นไป จัดระดับตามลม 61/118 กม./ชม.) **ทอร์นาโด** (พายุหมุนขนาดเล็กแรงสุด แบบซูเปอร์เซลล์)

## 🧠 ทำความเข้าใจ

### 1. พายุฝนฟ้าคะนอง (thunderstorm)

เมฆขนาดใหญ่**แนวดิ่ง** จากการยกตัวของอากาศร้อนชื้นสู่ชั้นอากาศเย็น → กลั่นตัวเป็นหยดน้ำ–น้ำแข็ง → เกิด**ลมกระโชก ฟ้าแลบ ฟ้าผ่า ฝนตกหนัก ลูกเห็บ**

**ขั้นตอนการเกิด 3 ขั้น**:
| ขั้น | เกิดอะไร |
|------|----------|
| **ก่อตัว** (cumulus stage) | กระแสอากาศไหล**ขึ้น** อากาศร้อนชื้นลอยตัวเย็นลงก่อตัวเป็นเมฆคิวมูลัส |
| **เติบโตเต็มที่** (mature stage) | อากาศพัด**ขึ้นลงรวดเร็ว** กลั่นตัว–เสียดสี → เม็ดฝน ลูกเห็บ ลม ประจุไฟฟ้า |
| **สลายตัว** (dissipating stage) | ไม่มีกระแสอากาศขึ้นลง ฝนลดลง พายุสลาย |

**ภัยตามมา**: ลมกระโชกแรง (โค่นต้นไม้ ป้าย) ฟ้าแลบ–ฟ้าผ่า / ลูกเห็บ (ฤดูร้อน) / ฝนตกหนัก → น้ำท่วมฉับพลัน–ดินถล่ม

**การจัดการ**: ระบบเตือนภัย สำรวจซ่อมหลังคา ตัดกิ่งไม้แก่ / **ติดตั้งสายล่อฟ้า**บนอาคารสูง / ส่วนตน: ก่อน — ติดตามพยากรณ์ เก็บของปลิวได้ / ขณะ — หลบที่กำบัง ปิดประตูหน้าต่าง ถอดปลั๊ก ไม่อยู่ที่โล่ง–ใต้ต้นไม้ใหญ่ ออกห่างชายหาด ถอดเครื่องประดับโลหะ / หลัง — อย่าออกที่โล่งทันที ต้นไม้โค่น–สายไฟขาดให้แจ้งเจ้าหน้าที่

### 2. พายุหมุนเขตร้อน (tropical cyclone)

พายุขนาดใหญ่เกิดเหนือมหาสมุทรเขตร้อนที่**อุณหภูมิผิวน้ำ 27°C ขึ้นไป** มักเกิดละติจูด **8–15°** เหนือ/ใต้

**โครงสร้าง**: ตาพายุ (ลมสงบ กดอกาศต่ำสุด) → กำแพงตาพายุ (ลมแรงที่สุด) → แถบฝนหมุนเป็นวงกว้าง 10–100 กม. → โตเต็มที่เส้นผ่านศูนย์กลาง ≥ 100 กม.

**ระดับความแรง (จำเลข 61/118)**:
| ระดับ | ความเร็วลมใกล้ศูนย์กลาง |
|-------|--------------------------|
| พายุดีเปรสชัน (tropical depression) | ≤ 61 กม./ชม. |
| พายุโซนร้อน (tropical storm) | 62–117 กม./ชม. |
| พายุไต้ฝุ่น (typhoon) | ≥ 118 กม./ชม. |

**ชื่อต่างตามมหาสมุทร**: **ไต้ฝุ่น** = แปซิฟิกตะวันตก (เอเชีย) / **เฮอริเคน** = แปซิฟิกตะวันออก–แอตแลนติก / **ไซโคลน** = มหาสมุทรอินเดีย

**ภัยตามมา**: ขึ้นฝั่ง → คลื่นพายุซัดฝั่ง ต้นไม้โค่น บ้านพัง / อยู่ทะเล → ลมแรงคลื่นใหญ่อันตรายต่อเรือ / ฝนตกหนัง → น้ำป่าไหลหลาก น้ำเอ่อล้น

**การจัดการ**: เตือนภัยลม–พายุ แผนระยะยาว กำหนดพื้นที่เสี่ยง / ส่วนตน: ก่อน — ซ่อมประตูหน้าต่าง ตัดต้นไม้เสี่ยงหัก เตรียมอุปกรณ์ฉุกเฉิน / ขณะ — หลบอาคารมั่นคง ไม่ใกล้เสาไฟ–ต้นไม้ ไม่อยู่ชายฝั่ง เรืองดออกจากฝั่ง / หลัง — ไม่ออกที่โล่งทันที ปฐมพยาบาล ไฟฟ้าล้มอย่าเข้าใกล้

### 3. พายุทอร์นาโด (tornado)

**พายุหมุนขนาดเล็กแต่พลังทำลายรุนแรง** ("พายุงวงช้าง") ศูนย์กลางกดอากาศต่ำมาก

**ประเภท 2 แบบ**:
| แบบ | เกิดจาก | ความรุนแรง |
|-----|---------|------------|
| **ซูเปอร์เซลล์** (supercell tornado) | พายุฝนฟ้าคะนองแบบซูเปอร์เซลล์ | สูงสุดถึง **EF4–EF5** ประจำแถบกลางสหรัฐฯ ฤดูร้อน–ปลายใบไม้ร่วง |
| **ไม่ใช่ซูเปอร์เซลล์** (nonsupercell tornado) | กลไกอื่น รัศมีแคบหมุนเร็ว | **EF0–EF2** รุนแรงน้อยกว่า เช่น พายุงวงช้างที่เกิดในไทย |

**การจัดการ**: แผนเตือนภัย + ประกาศแนวเคลื่อนที่ของพายุ / พื้นที่เสี่ยงควรมี**ที่หลบภัยในบ้าน** / ส่วนตน: ก่อน — ติดตามข่าว ทำหลุมหลบภัย / ขณะ — อพยพไปที่กำบังมั่นคง อยู่ห่างหน้าต่าง ปิดสวิตช์ไฟ รถที่ถูกพายุเคลื่อนเข้าใกล้ → ขับหนีเร็วที่สุด / หลัง — ปฐมพยาบาล สำรวจความเสียหาย แจ้งเจ้าหน้าที่ถ้าสายไฟเสียหาย

> [!info] ทอร์นาโดในไทย
> ไทยมีพายุงวงช้างบ้างแต่จัดอยู่แบบ**ไม่ใช่ซูเปอร์เซลล์** ความรุนแรงระดับ EF0–EF2 — หายากและแรงน้อยกว่าทอร์นาโดอเมริกา

## ✏️ ตัวอย่างการคำนวณ/วิเคราะห์

กรมอุตุนิยมวิทยารายงาน "พายุโซนร้อน X มีความเร็วลมใกล้ศูนย์กลาง 95 กม./ชม. และกำลังทวีกำลัง" — วิเคราะห์

1. 95 กม./ชม. อยู่ช่วง **62–117 กม./ชม.** → จัดเป็น**พายุโซนร้อน** (ยังไม่ใช่ไต้ฝุ่น)
2. ถ้าทวีกำลังเกิน **118 กม./ชม.** → ยกสถานะเป็น**พายุไต้ฝุ่น**
3. ผลที่ต้องเตรียม: เรือทุกชนิดงดออกจากฝั่ง / ชายฝั่งระวังคลื่นพายุซัดฝั่ง / พื้นที่ตอนในระวังฝนตกหนัก → น้ำป่าไหลหลาก–น้ำท่วมขัง
4. ถ้าลมอ่อนลงต่ำกว่า 61 กม./ชม. → ลดสถานะเป็น**พายุดีเปรสชัน** (ฝนตกเป็นแถบกว้าง ยังทำให้น้ำท่วมได้!)

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **ตาพายุ = ลมสงบ** ไม่ใช่พายุจบแล้ว — หลังผ่านตาพายุ กำแพงตาฝั่งตรงข้ามพัดลมแรงสุดกลับมาอีกรอบ
> 2. ไต้ฝุ่น/เฮอริเคน/ไซโคลน คือพายุ**ชนิดเดียวกัน** ต่างแค่ชื่อเรียกตามมหาสมุทร — ไม่ใช่พายุต่างประเภท
> 3. **ทอร์นาโดเล็กกว่าพายุหมุนเขตร้อนมาก** แต่แรงลมทำลายสูงกว่า (EF5) — เล็ก ≠ อ่อน
> 4. พายุดีเปรสชัน (กำลังอ่อน) **ยังทำให้น้ำท่วมได้** เพราะฝนตกเป็นแถบกว้างต่อเนื่อง อย่าประมาท
> 5. ขณะฝนฟ้าคะนอง **ห้ามใส่เครื่องประดับโลหะ** และห้ามยืนใต้ต้นไม้ใหญ่ — โลหะ/ต้นสูงดึงดูดฟ้าผ่า

## 🏋️ แบบฝึกหัด

> [!question]- ข้อ 1: พายุที่เกิดเหนือมหาสมุทรแอตแลนติกและพัดเข้าสหรัฐอเมริกา เรียกว่าอะไร ถ้ามีลมใกล้ศูนย์กลาง 140 กม./ชม. จัดอยู่ระดับใด
> > [!success]- เฉลย
> > เรียกว่า**เฮอริเคน (hurricane)** — พายุหมุนเขตร้อนชนิดเดียวกับไต้ฝุ่น แต่ใช้ชื่อตามบริเวณแอตแลนติก–แปซิฟิกตะวันออก
> > ลม 140 กม./ชม. > 118 กม./ชม. → อยู่ระดับ**พายุไต้ฝุ่น** (ระดับแรงมากที่สุดของพายุหมุนเขตร้อน)

> [!question]- ข้อ 2: อธิบายว่าเหตุใด "ตาพายุ" จึงมีลมสงบ และประชาชนควรปฏิบัติอย่างไรเมื่อตาพายุเคลื่อนผ่าน
> > [!success]- เฉลย
> > ตาพายุคือ**ศูนย์กลางความกดอากาศต่ำ** อากาศในตาค่อนข้างนิ่ง (อากาศไหลลงอ่อน ๆ ชดเชย) จึงเกิด**โซนลมสงบ** ท้องฟ้าเปิดบางครั้ง
> > การปฏิบัติ: **ห้ามออกจากที่หลบภัย**เมื่อลมหยุดเพราะคิดว่าพายุผ่านไปแล้ว — ข้างหลังตาพายุคือ**กำแพงตาพายุฝั่งตรงข้าม** ซึ่งพัดลมแรงที่สุดเข้ามาภายในเวลาสั้น ๆ ต้องรอจนทางราชการประกาศว่าพายุพ้นจริง

> [!question]- ข้อ 3: เปรียบเทียบพายุทอร์นาโดซูเปอร์เซลล์ของสหรัฐฯ กับพายุงวงช้างในไทย ต่างกันที่ความรุนแรงระดับใด เพราะอะไรจึงต่าง
> > [!success]- เฉลย
> > **ซูเปอร์เซลล์** (สหรัฐฯ): เกิดจากพายุฝนฟ้าคะนองแบบซูเปอร์เซลล์ → รุนแรงสูงสุด **EF4–EF5** ลมทำลายทุกอย่างบนเส้นทาง
> > **ไม่ใช่ซูเปอร์เซลล์** (งวงช้างไทย): เกิดจากกลไกท้องถิ่น รัศมีแคบหมุนเร็วแต่พลังน้อยกว่า → ระดับ **EF0–EF2**
> > สาเหตุความต่าง: พายุแม่แบบ (ซูเปอร์เซลล์) มีโครงสร้างแนวดิ่งที่สูงใหญ่พร้อมการหมุนอากาศทั้งระบบ ให้พลังงานมหาศาลต่อทอร์นาโดที่ก่อตัว ขณะที่แบบท้องถิ่นมีพลังงานจำกัดกว่า

ไต้ฝุ่น เฮอริเคน ไซโคลน ต่างกันอย่างไร?::เป็นพายุชนิดเดียวกัน ต่างชื่อตามมหาสมุทร — ไต้ฝุ่น (แปซิฟิกตะวันตก) เฮอริเคน (แอตแลนติก) ไซโคลน (มหาสมุทรอินเดีย)

ตาพายุคืออะไร?::ศูนย์กลางพายุที่ลมสงบและเป็นจุดความกดอากาศต่ำที่สุด ล้อมด้วยกำแพงตาพายุที่ลมแรงที่สุด

ทอร์นาโดซูเปอร์เซลล์กับไม่ใช่ซูเปอร์เซลล์ต่างกันอย่างไร?::ซูเปอร์เซลล์ เกิดจากพายุฝนฟ้าคะนองแบบซูเปอร์เซลล์ แรงสูงสุด EF4–EF5 / ไม่ใช่ซูเปอร์เซลล์ แรง EF0–EF2 เช่น พายุงวงช้างไทย

ภัยตามมาจากพายุหมุนเขตร้อน?::คลื่นพายุซัดฝั่งเมื่อขึ้นฝั่ง ลมแรงคลื่นใหญ่อันตรายต่อเรือ และฝนตกหนักทำให้น้ำป่าไหลหลาก–น้ำท่วมขัง

ป้องกันฟ้าผ่าทำอย่างไร?::ติดตั้งสายล่อฟ้าบนอาคาร ไม่ยืนใต้ต้นไม้ใหญ่หรือที่โล่งแจ้ง ถอดเครื่องประดับโลหะ ปิดประตูหน้าต่าง ถอดปลั๊กเครื่องใช้ไฟฟ้า
