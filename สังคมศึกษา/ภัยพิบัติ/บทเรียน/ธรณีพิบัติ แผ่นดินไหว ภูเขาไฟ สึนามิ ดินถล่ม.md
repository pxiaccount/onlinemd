# ธรณีพิบัติ: แผ่นดินไหว ภูเขาไฟ สึนามิ ดินถล่ม

> [!abstract] สรุปในหนึ่งบรรทัด
> ธรณีพิบัติคือภัยจาก**การเคลื่อนตัวของเปลือกโลก** — แผ่นดินไหว (รอยเลื่อนปลดปล่อยพลังงาน) ภูเขาไฟปะทุ (แมกมาดันขึ้น) สึนามิ (แผ่นดินไหวใต้ทะเลกระตุ้นคลื่น) และแผ่นดินถล่ม (มวลดินเลื่อนตามแรงโน้มถ่วง)

## 🧠 ทำความเข้าใจ

### 1. แผ่นดินไหว (earthquake)

การสั่นสะเทือนของเปลือกโลก — ขนาดมากกว่า 5 ริกเตอร์จะรุนแรง สูญเสียชีวิต–ทรัพย์สินมาก

**กระบวนการ**: รอยเลื่อนมีพลังในแผ่นธรณีภาค → แรงเค้น/ความเครียดสะสมใต้เปลือกโลกอย่างช้า ๆ → เปลี่ยนแปลงฉับพลัน → ปลดปล่อยพลังงานเป็น**คลื่นไหวสะเทือน** (อีกสาเหตุ: ภูเขาไฟปะทุ)

**ประเภทรอยเลื่อนมีพลัง 3 แบบ**:
| แบบ | การเคลื่อนตัว |
|-----|---------------|
| รอยเลื่อนปกติ (normal fault) | หินเพดานเลื่อน**ลง**เทียบหินพื้น |
| รอยเลื่อนย้อน (reverse fault) | หินเพดานเลื่อน**ขึ้น**เทียบหินพื้น |
| รอยเลื่อนตามแนวระดับ (strike-slip fault) | สองด้านเฉือนกันใน**แนวราบ** |

**ภัยตามมา**: สิ่งก่อสร้างพัง / แผ่นดินแยก–ทรุด / ไฟไหม้ (ท่อแก๊สรั่ว) / **สึนามิ** / แผ่นดินถล่ม

**การจัดการ**: ตรวจสภาพ–เสริมความแข็งแรงอาคาร / ซักซ้อมหลบภัย / เผยแพร่ความรู้ ส่วนตน: ยึดเครื่องเรือนให้มั่นคง ไม่วางของหนักบนที่สูง / ขณะสั่น: ระวังของตก อย่าใช้ลิฟต์ ถ้าอยู่นอกอาคารให้ห่างตึกสูง–กำแพง / หลังเกิด: ตรวจร่างกาย ใส่รองเท้าหุ้มส้นเดินท่ามกลางซาก

### 2. ภูเขาไฟปะทุ (volcanic eruption)

ทั่วโลกมีภูเขาไฟมีพลัง ~**1,500 ลูก** ส่วนใหญ่อยู่**วงแหวนแห่งไฟ**ในมหาสมุทรแปซิฟิก

**กระบวนการ**: ใต้เปลือกโลกแมกมาไหลเวียนตลอด → จุดอ่อนของเปลือกโลก (รอยต่อแผ่นเปลือกโลก มุดเข้าหากัน/แยกออก) → แรงดันสูงพาแมกมาขึ้นตามรอยแตก

**ประเภทตามสถานะ**: มีพลัง (active — ปะทุได้ทุกเมื่อ เช่น เอ็ตนา) / สงบ (dormant — พอแรงเพิ่มอาจปะทุใหม่ เช่น ฟูจิ) / ดับสนิท (extinct — เช่น **เขาพนมรุ้งไทย**, บูนินยองออสเตรเลีย)

**ประเภทตามความรุนแรงของการปะทุ**:
| แบบ | ลักษณะ |
|-----|---------|
| **พลิเนียน** (Plinian) | รุนแรง**มากที่สุด** ลาวาเหนียวข้น พ่นเถ้า–หิน–แก๊สถึงชั้นสแตรโทสเฟียร์ |
| **วัลเคเนียน** (Vulcanian) | รุนแรงช่วงสั้น ระเบิดเศษหิน ควันเป็นรูปดอกเห็ด |
| **สตรอมโบเลียน** (Strombolian) | ลาวาเหลวพวยพุ่งเป็นจังหวะสั้น ๆ |
| **ฮาวายเอียน** (Hawaiian) | รุนแรง**น้อยสุด** ลาวาเหลวไหล–พ่นเป็นลำคล้ายน้ำพุ → เกิดภูเขาไฟรูปโล่ |

**ภัยตามมา**: แก๊สภูเขาไฟ (เป็นกรด ระคายเคือง) / ทีฟรา (tephra — ตะกอนพ่นขึ้นฟ้า) / ลาวาหลาก / แผ่นดินถล่มข้างภูเขาไฟ / **ลาฮาร์** (lahar — โคลนจากเถ้าภูเขาไฟ) / **หินตะกอนภูเขาไฟหลาก** (pyroclastics — เถ้า–หินร้อนไหลเร็วมาก เผาได้ทุกอย่าง)

**การจัดการ**: เตือนภัยล่วงหน้า ประชาสัมพันธ์ แผนอพยพ / ส่วนตน: ทางการสั่งอพยพให้ออกทันที สวมหน้ากากกันฝุ่น ไม่หลบอาคารไม่แข็งแรง

### 3. สึนามิ (tsunami)

คลื่นยักษ์จากแผ่นดินไหว/ภูเขาไฟใต้ทะเล เคลื่อนที่ **500–700 กม./ชม.** — ในทะเลลึกคลื่นต่ำแต่ยาวมาก เข้าชายฝั่งจะ**ช้าลงแต่สูงขึ้น**แล้วโถมเข้าทำลาย (คำว่า "สึนามิ" ภาษาญี่ปุ่นแปลว่า คลื่นท่าเรือ)

**สาเหตุ 4 อย่าง**: แผ่นดินไหวใต้ทะเล / เกาะภูเขาไฟปะทุ / แผ่นดินถล่มใหญ่ใต้ทะเล (ไหล่ทวีป) / อุกกาบาตตกในทะเล (พบน้อย)

**ภัยตามมา**: น้ำเค็มท่วมแหล่งน้ำจืด / ปะการัง–ป่าชายเลนหักโค่น / อาคาร–สาธารณูปโภคเสียหาย / เสียชีวิตมนุษย์–สัตว์จำนวนมาก

**การจัดการ**: ติดตั้งระบบเตือนภัย (ทุ่นลอย) ป้ายเส้นทางอพยพ ซ้อมรับมือ / ส่วนตน: รู้สึกแผ่นดินสั่นรุนแรงที่ชายหาด → **รีบขึ้นที่สูงทันที** ไม่ต้องรอประกาศ / อยู่บนเรือ → ลอยออกกลางทะเล (ทะเลลึกปลอดภัยกว่าฝั่ง)

### 4. แผ่นดินถล่ม (landslide)

การเคลื่อนที่ของมวลดิน–เศษหินตามแรงโน้มถ่วง ในพื้นที่ลาดชัน โดยมี**น้ำหรือแรงสั่นสะเทือน**เป็นตัวกระตุ้น

**กระบวนการ**: ฝนตกหนักต่อเนื่อง → น้ำซึมสะสมในดิน พื้นที่ลาดชัน (เกิน ~30 องศา) รับน้ำหนักไม่ไหว → ทรุดและไหลลง → ทับสิ่งก่อสร้างเชิงเขา (ในเขาหินปูนอาจเกิดหลุมยุบ)

**สาเหตุ**: ธรรมชาติ — แผ่นดินไหว ฝนตกหนักต่อเนื่อง / มนุษย์ — เพาะปลูก–สร้างบ้านบนลาดชัน ตัดไม้ทำลายป่า ตัดถนนตามไหล่เขา

**การจัดการ**: ระบบเตือนภัย + อาสาสมัครหมู่บ้านส่งสัญญาณ / ห้ามถางป่าต้นน้ำ / ปลูกพืชคลุมดินยึดหน้าดิน / ส่วนตน: สังเกตสัญญาณ จัดเวรเฝ้าระวัง / ขณะเกิด: อพยพขึ้นที่สูง อยู่ห่างลำน้ำ / หลังเกิด: ห้ามกลับบ้านที่ถูกดินถล่มทันที

## ✏️ ตัวอย่างการวิเคราะห์

พ.ศ. 2547 คลื่นสึนามิซัดอันดามัน — อธิบายลำดับเหตุการณ์และบทเรียนการจัดการ

1. **สาเหตุ**: แผ่นเปลือกโลกมุดกันใต้มหาสมุทรอินเดีย → แผ่นดินไหวใต้ทะเลขนาดใหญ่
2. **การก่อตัว**: เปลือกโลกเคลื่อนตัวกระตุ้นน้ำ → คลื่นกระจายทุกทิศ ความเร็ว 500–700 กม./ชม.
3. **เข้าฝั่ง**: น้ำตื้น → คลื่นช้าลง สูงขึ้นหลายเมตร → โถมทำลายชายฝั่ง 6 จังหวัดภาคใต้
4. **บทเรียน**: ไทยติดตั้งระบบเตือนภัย ป้ายเส้นทางอพยพ ซ้อมรับมือ — และถ้ารู้สึกแผ่นดินสั่นแรงที่ชายหาด ต้องรีบขึ้นที่สูง**ทันที**โดยไม่รอประกาศ

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **รอยเลื่อนปกติ ≠ รอยเลื่อนย้อน** — ปกติ: หินเพดานเลื่อน**ลง** / ย้อน: หินเพดานเลื่อน**ขึ้น** (จำ: "ย้อน = ยกขึ้น")
> 2. **ลาวาหลาก** เคลื่อนที่**ช้า** (หนีทัน) แต่ **pyroclastics** (หินตะกอนภูเขาไฟหลาก) ไหล**เร็วมาก** ร้อนจัด — อันตรายกว่ามาก
> 3. **ลาฮาร์** ไม่ใช่ลาวา — คือโคลนจากเถ้าภูเขาไฟผสมน้ำ
> 4. ภูเขาไฟ**สงบ (dormant)** ยังปะทุใหม่ได้ ต่างจาก**ดับสนิท (extinct)** ที่ไม่ปะทุอีกแล้ว
> 5. อยู่**บนเรือ**เมื่อเกิดสึนามิ ให้ลอยออก**กลางทะเลลึก** ไม่ใช่รีบเข้าฝั่ง
