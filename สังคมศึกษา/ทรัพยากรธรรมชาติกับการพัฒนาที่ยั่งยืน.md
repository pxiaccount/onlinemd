# ทรัพยากรธรรมชาติกับการพัฒนาที่ยั่งยืน

> [!abstract] สรุปในหนึ่งบรรทัด

## 🧠 ทำความเข้าใจ

### 1. การเปลี่ยนแปลงสภาพภูมิอากาศ

**กลไกเรือนกระจก**: ปกติรังสีความร้อนจากโลกสะท้อนออกสู่อวกาศทำให้อุณหภูมิพอเหมาะ แต่เมื่อแก๊สเรือนกระจก (**CO₂ CH₄ N₂O**) เยอะขึ้น รังสีความร้อนถูกดูดซับไว้ → อุณหภูมิสูงขึ้น

**สาเหตุ**:
- ธรรมชาติ: พลังงานความร้อนจากดวงอาทิตย์เปลี่ยนแปลง
- มนุษย์: เผาถ่านหิน น้ำมันดิบ แก๊สธรรมชาติ → CO₂ เพิ่ม

**ผลกระทบ**: ฝนตกผิดฤดู เกษตรลดผลผลิต / ชะล้างพังทลาย ดินเสื่อม / **ระดับน้ำทะเลขึ้น** (น้ำแข็งขั้วโลกละลาย) / ภัยธรรมชาติรุนแรง (ภัยแล้ง ไฟป่า อุทกภัย) / สิ่งมีชีวิตเสี่ยงสูญพันธุ์ / น้ำจืดลดลง

**แนวทางแก้ (ระดับโลก)**:
| กลไก | สาระสำคัญ |
|------|-----------|
| กรอบอนุสัญญาสหประชาชาติ (UNFCCC) | ประเทศพัฒนาแล้วต้องลดแก๊สเรือนกระจก + ช่วยประเทศอื่น |
| พิธีสารเกียวโต (Kyoto Protocol) | ลดการปล่อยไม่น้อยกว่า **ร้อยละ 5** ระยะ 1 พ.ศ. 2551–2555 ระยะ 2 พ.ศ. 2556–2563 |
| 3 กลไกดำเนินการ | 1) การดำเนินการร่วม 2) การซื้อขายแก๊สเรือนกระจก 3) กลไกการพัฒนาที่สะอาด |

**การมีส่วนร่วมของเรา**: ใช้พลังงานสะอาด / ลดใช้รถส่วนตัว / ปิดเครื่องใช้ไฟฟ้าที่ไม่ใช้ / ลดโฟม–ถุงพลาสติก / ปลูกต้นไม้

### 2. ความหลากหลายทางชีวภาพ

โลกกำลังสูญเสียสัตว์–พืชป่าเขตร้อนอย่างน้อย **27,000 ชนิด/ปี** หรือ **3–4 สปีชีส์ต่อชั่วโมง**

**ปัจจัย**: ประชากรเพิ่ม–รุกล้ำแหล่งชุมชนชีวภาพ / ภูมิอากาศเปลี่ยน / ใช้ทรัพยากรสิ้นเปลือง / มลพิษ (ทิ้งขยะลงแม่น้ำ) / เทคโนโลยีชีวภาพ

### 3. องค์กรด้านสิ่งแวดล้อม

**ของไทย**:
| หน่วยงาน | ภารกิจ |
|----------|---------|
| กรมส่งเสริมคุณภาพสิ่งแวดล้อม | ความร่วมมือวิจัยโลกร้อน สัมมนา อบรมชุมชนปลอดขยะ |
| กรมควบคุมมลพิษ | จัดการมลพิษน้ำ อากาศ เสียง ขยะมูลฝอย ตามอนุสัญญาบาเซิล |
| สำนักงานนโยบายและแผน ทส. | กำหนดนโยบายและแผนคุ้มครองสิ่งแวดล้อม |
| องค์กรพัฒนาเอกชน (NGO) ไทย | มูลนิธิโลกสีเขียว (สื่อ/ข่าวสาร) มูลนิธิสืบนาคะเสถียร (อนุรักษ์ป่า–สัตว์ป่า) |
| องค์กรโลก | **กรีนพีซ** (Greenpeace), **มูลนิธิคุ้มครองสัตว์ป่าโลก** (WWF) |

**อนุสัญญาระหว่างประเทศ**:
| อนุสัญญา | วัตถุประสงค์ |
|----------|--------------|
| **CITES** (การค้าสัตว์ป่า–พืชป่าใกล้สูญพันธุ์) | ควบคุม/ห้ามลักลอบค้าสัตว์ป่าพืชป่าข้ามประเทศ |
| **UNFCCC** (การเปลี่ยนแปลงสภาพภูมิอากาศ) | รักษาระดับแก๊สเรือนกระจกไม่ให้เป็นอันตราย |
| **แรมซาร์** (พื้นที่ชุ่มน้ำ) | อนุรักษ์–ฟื้นฟูพื้นที่ชุ่มน้ำทั่วโลก |
| **บาเซิล** (ของเสียอันตราย) | ควบคุมการเคลื่อนย้ายข้ามแดนของของเสียอันตราย คุ้มครองประเทศกำลังพัฒนา |
| **CBD** (ความหลากหลายทางชีวภาพ) | อนุรักษ์ / ใช้ประโยชน์อย่างยั่งยืน / แบ่งปันผลประโยชน์อย่างเท่าเทียม |

### 4. หลักการจัดการทรัพยากรธรรมชาติ

1. ควบคุมจำนวนประชากร
2. ส่งเสริมคุณภาพประชากร (ปลูกจิตสำนึกอนุรักษ์)
3. สำรวจแหล่งทรัพยากรเพิ่ม
4. ป้องกันรักษาไม่ให้เสื่อมโทรม
5. ใช้ทรัพยากรให้ถูกประเภท
6. ใช้ทดแทนกัน (ปุ๋ยอินทรีย์ ฟื้นฟูป่า)
7. ใช้วัสดุอื่นทดแทน (พลาสติกแทนโลหะ–ไม้)
8. นำกลับมาใช้ใหม่ (กระดาษผลิตใหม่)

**หลัก 7R**: **Reject** ปฏิเสธการใช้ / **Reduce** ลดการใช้ / **Reuse** ใช้ซ้ำ / **Repair** ซ่อมแซม / **Renewal** เสริมแต่งของเก่า / **Recovery** ถนอมรักษา / **Recycle** ผลิตขึ้นใหม่

## ✏️ ตัวอย่างการประยุกต์

โรงเรียนหนึ่งต้องการลดขยะพลาสติกหน้าโรงอาหารด้วยหลัก 7R — ทำอย่างไร?

1. **Reject**: ปฏิเสธถุงพลาสติก–ช้อนพลาสติกจากร้านค้า ให้นักเรียนพกกล่องข้าว
2. **Reduce**: ลดขวดน้ำเปล่า ติดตั้งตู้น้ำดื่มให้เติมได้
3. **Reuse**: ขวดแก้ว–กล่องพลาสติกหนาใช้ซ้ำได้หลายครั้ง
4. **Repair**: ช่องแยกประเภทขยะพัง ซ่อมไม่ทิ้ง
5. **Renewal**: เก้าอี้ไม้เก่าขัด–ทาสีใหม่ใช้ต่อ
6. **Recovery**: เก็บรักษาวัสดุเหลือใช้ไว้ทำกิจกรรม
7. **Recycle**: ขวด PET แยกขายให้คัดแยก นำไปรีไซเคิลเป็นเส้นใยผ้า

→ ขยะลดลงทั้งต้นทาง (Reject/Reduce) และปลายทาง (Recycle)

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **UNFCCC ≠ Kyoto Protocol** — UNFCCC คือกรอบอนุสัญญาใหญ่ (สร้างเงื่อนไข) พิธีสารเกียวโตคือข้อผูกพันลดแก๊สจริง (≥5%) ใต้กรอบนั้น
> 2. อนุสัญญา **แรมซาร์** ว่าด้วย**พื้นที่ชุ่มน้ำ** ไม่ใช่ทะเล — จำจาก "ชุ่มน้ำ = บึง หนอง ป่าชายเลน"
> 3. **บาเซิล** เกี่ยวกับ**ของเสียอันตรายข้ามแดน** ไม่ใช่มลพิษอากาศ
> 4. 7R ไม่ใช่ 3R — เพิ่ม Reject, Repair, Renewal, Recovery; ลำดับที่ดีที่สุดคือลดตั้งแต่ต้นทาง (Reject มาก่อน Recycle)

## 🏋️ แบบฝึกหัด

> [!question]- 1 ประเทศ A ต้องการส่งขยะอิเล็กทรอนิกส์ไปฝังกลบในประเทศ B ซึ่งเป็นประเทศกำลังพัฒนา อนุสัญญาใดที่ใช้ควบคุมสถานการณ์นี้ และคุ้มครองอะไร
> > [!success]- เฉลย
> > **อนุสัญญาบาเซิล (Basel Convention)** — ว่าด้วยการควบคุมการเคลื่อนย้ายข้ามแดนของของเสียอันตรายและการกำจัด
> > คุ้มครอง: สุขภาพอนามัยของมนุษย์และสิ่งแวดล้อม โดยเฉพาะป้องกันอันตรายต่อสิ่งแวดล้อมในประเทศกำลังพัฒนา → การส่งขยะเช่นนี้ต้องได้รับการควบคุม/ห้าม

> [!question]- 2 โลกสูญเสียสิ่งมีชีวิตประมาณกี่สปีชีส์ต่อชั่วโมง และยกปัจจัยจากมนุษย์ 3 ข้อที่ทำให้เกิดการสูญเสียนี้
> > [!success]- เฉลย
> > ประมาณ **3–4 สปีชีส์ต่อชั่วโมง** (รวม ~27,000 ชนิด/ปี)
> > ปัจจัยจากมนุษย์ 3 ข้อ เช่น:
> > 1. จำนวนประชากรเพิ่ม → รุกล้ำพื้นที่ที่มีความหลากหลายสูง
> > 2. ใช้ทรัพยากรธรรมชาติอย่างสิ้นเปลืองเพื่อการค้า
> > 3. เกิดมลพิษ เช่น ทิ้งขยะมูลฝอยลงแม่น้ำลำคลอง

> [!question]- 3 "พี่ชายโยนขวดน้ำพลาสติกลงถังรีไซเคิลแล้วรู้สึกว่าตัวเองช่วยโลกเต็มที่แล้ว" วิเคราะห์ด้วยหลัก 7R ว่ายังทำอะไรได้ดีกว่านี้
> > [!success]- เฉลย
> > รีไซเคิลคือขั้น**ท้าย ๆ** ของ 7R — ที่ดีกว่าคือลดตั้งแต่ต้นทาง:
> > - **Reject**: ไม่ซื้อขวดพลาสติกเลย ใช้กระติกน้ำส่วนตัว
> > - **Reduce**: ลดจำนวนขวดที่ซื้อ
> > - **Reuse**: ขวดเดิมเติมน้ำใช้ซ้ำหลายครั้งก่อนทิ้ง
> > → ปฏิบัติตามลำดับ Reject → Reduce → Reuse ก่อนถึง Recycle จะลดขยะได้จริงกว่า
