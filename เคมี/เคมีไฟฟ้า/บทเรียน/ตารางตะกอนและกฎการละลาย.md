# ตารางตะกอน: จะรู้ได้ไงว่าตะกอนสีนั้นคือสารอะไร

> [!abstract] สรุปในหนึ่งบรรทัด
> เวลาผสมสารละลาย 2 ชนิดแล้วเกิดตะกอน = เกิด**เกลือที่ละลายน้ำไม่ได้**ขึ้นใหม่ — ดูจาก **กฎการละลาย (solubility rules)** หาตัวผิด แล้วจำ**สีตะกอนเด่น** ไม่กี่สีก็แทบตอบได้ทุกข้อสอบ

## 🧠 ทำความเข้าใจ

เวลาเจอโจทย์ "ผสมสารละลาย A กับ B ได้ตะกอนสี X" — ตะกอนนั้นคือผลของการ**จับคู่ไอออนใหม่** จากวิธีแตกตัว:

$$\mathrm{Pb(NO_3)_2 \rightarrow Pb^{2+} + 2NO_3^-} \qquad \mathrm{KI \rightarrow K^+ + I^-}$$

จับคู่ใหม่ได้ 2 คู่: **PbI₂** กับ **KNO₃** — แล้วถามว่า "ใครละลายน้ำไม่ได้?" คนที่ละลายไม่ได้แหละคือตะกอน

คำตอบมาจาก **กฎการละลาย** (จำไม่ต้องครบ จำเฉพาะข้อยกเว้นก็พอ):

## ✏️ กฎการละลาย + ตารางจำ

**กฎหลัก (ละลายได้เกือบทั้งหมด):**

| กฎ | ละลายได้? |
|---|---|
| สารประกอบของ **NO₃⁻** (ไนเทรต) | ✅ ละลายหมดทุกตัว |
| สารประกอบของ **โลหะแอลคาไล** (Li⁺ Na⁺ K⁺) และ **NH₄⁺** | ✅ ละลายหมดทุกตัว |
| สารประกอบของ **Cl⁻, Br⁻, I⁻** (ไฮไลด์) | ✅ ละลายได้ **ยกเว้น** Ag⁺, Pb²⁺, Hg₂²⁺ |
| สารประกอบของ **SO₄²⁻** | ✅ ละลายได้ **ยกเว้น** Ba²⁺, Pb²⁺, Ca²⁺ (ละลายน้อย) |

**ตัวที่ละลายไม่ได้ (ตะกอนตัวยง):**

| กฎ | ละลายได้? |
|---|---|
| **CO₃²⁻** (คาร์บอเนต), **PO₄³⁻** (ฟอสเฟต), **S²⁻** (ซัลไฟด์) | ❌ ยกเว้นกับแอลคาไล/NH₄⁺ |
| **OH⁻** (ไฮดรอกไซด์) | ❌ ยกเว้นแอลคาไล, Ba²⁺ (Ca²⁺ ละลายน้อย) |

**สีตะกอนที่ออกสอบบ่อย:**

| ตะกอน | สี | มาจากคู่ไหนบ่อย |
|---|---|---|
| **PbI₂** | 🟡 เหลืองสด | Pb(NO₃)₂ + KI |
| **AgI** | 🟡 เหลือง | AgNO₃ + KI |
| **AgCl** | ⚪ ขาว | AgNO₃ + HCl / NaCl |
| **PbCl₂** | ⚪ ขาว | Pb(NO₃)₂ + HCl |
| **BaSO₄** | ⚪ ขาว | BaCl₂ + H₂SO₄/Na₂SO₄ |
| **CaCO₃** | ⚪ ขาว | CaCl₂ + Na₂CO₃ |
| **Cu(OH)₂** | 🔵 ฟ้า | CuSO₄ + NaOH |
| **Fe(OH)₃** | 🟤 น้ำตาล | FeCl₃ + NaOH |
| **PbS** | ⚫ ดำ | Pb(NO₃)₂ + Na₂S |
| **ZnS / FeS** | ⚪ ขาว / ⚫ ดำ | ซัลไฟด์ทั่วไป |

> [!tip] เทคนิคจำ
> **"ไนเทรต + แอลคาไล = ละลายหมด"** — สองกลุ่มนี้ไม่มีวันเป็นตะกอน
> **"ฮาไลด์กับเงิน-ตะกั่ว = ตกตะกอน"** — Ag⁺ กับ Pb²⁺ คือตัวร้ายที่ทำให้ Cl⁻/I⁻ ตกตะกอน
> สีเหลืองแทบ = **ไอโอไดด์ (I⁻)** เสมอในระดับ ม.ปลาย — เห็นตะกอนเหลืองให้นึกถึง PbI₂ หรือ AgI ก่อน

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. คิดว่าทุกอย่างละลายน้ำได้ — เกลือบางตัวละลายไม่ได้เลย ต้องจำข้อยกเว้น Ag⁺/Pb²⁺ ให้ขึ้นใจ
> 2. เขียนสมการไอออนิกไม่ได้ — ตัวที่เป็น**ตะกอน (s)** ห้ามแตกเป็นไอออน (เขียน $\mathrm{PbI_2(s)}$ ไม่ใช่ $\mathrm{Pb^{2+} + 2I^-}$ ฝั่งขวา)
> 3. จำสีเหลือง = Br⁻ (จริง ๆ AgBr เป็น**ครีม/เหลืองอ่อน**) ส่วน I⁻ เหลืองสดกว่าชัดเจน
> 4. ลืมดูว่าโจทย์ให้สารละลายเข้มข้นมาก — ตัวที่ "ละลายน้อย" เช่น CaSO₄ ก็อาจตกตะกอนได้ในสารละลายเข้ม
