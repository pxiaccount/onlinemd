# เซลล์กัลวานิก (Galvanic Cell)

> [!abstract] สรุปในหนึ่งบรรทัด
> เซลล์กัลวานิกคืออุปกรณ์เปลี่ยน**พลังงานเคมีจากปฏิกิริยารีดอกซ์**ให้เป็น**พลังงานไฟฟ้า** — โลหะที่ออกซิไดซ์เป็นขั้วลบ (anode) สารที่ถูกรีดิวซ์อยู่ขั้วบวก (cathode) และอิเล็กตรอนไหลจากขั้วลบไปขั้วบวกผ่านสายไฟ

$
\text{Zn} + \text{Cu}^{2+} \rightarrow \text{Zn}^{2+} + \text{Cu} \quad E^0_{cell} = +1.10 \text{ V}
$

> [!important] จำหลักการสำคัญ
> **AN OX / RED CAT** — **Ox**idation ที่ **An**ode (ขั้วลบ) / **Red**uction ที่ **Cat**hode (ขั้วบวก) และอิเล็กตรอนไหล**จาก anode → cathode** เสมอ

อิเล็กตรอนไหลจากแผ่น Zn (ขั้วลบ) ผ่านสายไฟเข้าแผ่น Cu (ขั้วบวก) ทำให้หลอดไฟติด ส่วนสะพานเกลือ (เขียว) เคลื่อนย้ายไอออนเพื่อคงสภาพเป็นกลางทางไฟฟ้าของทั้งสองถ้วย

## 🧠 ทำความเข้าใจ

ลองนึกภาพว่า Zn กับ Cu²⁺ เป็นเหมือนคนสองคนที่อยากแลกของกัน: **Zn อยากสละอิเล็กตรอน** (มันใจดี ยอมให้ง่าย) ส่วน **Cu²⁺ อยากรับอิเล็กตรอน** ถ้าจุ่มแผ่น Zn ลงในสารละลาย CuSO₄ ตรง ๆ ปฏิกิริยาจะเกิดรวดเร็วแต่พลังงานออกมาเป็น**ความร้อน**เท่านั้น

เซลล์กัลวานิกฉลาดกว่าตรงที่**แยกสองปฏิกิริยาออกจากกันคนละถ้วย** แล้วบังคับให้อิเล็กตรอนเดินทางผ่าน**สายไฟ**แทน — อิเล็กตรอนที่ไหลผ่านสายไฟก็คือกระแสไฟฟ้าที่เราเอาไปใช้งานได้ เช่น ติดหลอดไฟ นั่นเอง

### องค์ประกอบของเซลล์

| ส่วน | หน้าที่ |
|------|---------|
| ขั้วลบ (anode) | เกิด**ออกซิเดชัน** — โลหะละลายเป็นไอออนบวก + ปล่อยอิเล็กตรอน |
| ขั้วบวก (cathode) | เกิด**รีดักชัน** — ไอออนบวกรับอิเล็กตรอนกลายเป็นโลหะเกาะที่ขั้ว |
| สะพานเกลือ | เชื่อมวงจรไฟฟ้า + รักษาความเป็นกลางทางไฟฟ้าโดยปล่อยไอออนลบ (anion) ไปด้าน anode และไอออนบวก (cation) ไปด้าน cathode |
| เกลือในสะพาน | ต้องเฉื่อย ไม่ทำปฏิกิริยา เช่น KNO₃, KCl, Na₂SO₄ |

### ปฏิกิริยาในเซลล์ Zn–Cu (เซลล์แดเนียล)

- ขั้วลบ (anode): $\text{Zn} \rightarrow \text{Zn}^{2+} + 2e^-$ — แผ่น Zn ค่อย ๆ **สึกกร่อน**
- ขั้วบวก (cathode): $\text{Cu}^{2+} + 2e^- \rightarrow \text{Cu}$ — แผ่น Cu **หนาขึ้น**
- ปฏิกิริยารวม: $\text{Zn} + \text{Cu}^{2+} \rightarrow \text{Zn}^{2+} + \text{Cu}$

### ศักย์ไฟฟ้ามาตรฐาน

$
E^0_{cell} = E^0_{cathode} - E^0_{anode} = (+0.34) - (-0.76) = +1.10 \text{ V}
$

- ค่า $E^0_{cell}$ เป็น**บวก** = ปฏิกิริยาเกิดได้เอง (spontaneous)
- โลหะที่ออกซิไดซ์ง่ายกว่า (ต่ำกว่าในซีรีส์ไฟฟ้าเคมี) เป็น**ขั้วลบ**เสมอ

> [!info] เกร็ดความรู้
> เซลล์กัลวานิกตั้งชื่อตาม **ลุยจี กัลวานี** นักฟิสิกส์ชาวอิตาลีที่สังเกตว่าขากบกระตุกเมื่อถูกโลหะสองชนิดแตะพร้อมกัน ต่อมา **อเลสซานโดร โวลตา** พัฒนาเป็นเซลล์ไฟฟ้าเคมีตัวแรกของโลก — จึงมีอีกชื่อว่า *เซลล์โวลตาอิก* และหน่วย "โวลต์" ก็มาจากชื่อเขา

## ✏️ ตัวอย่างการคำนวณ

**โจทย์ 1:** เซลล์ที่มี $\text{Mg} \,|\, \text{Mg}^{2+}$ ($E^0 = -2.37$ V) คู่กับ $\text{Ag} \,|\, \text{Ag}^+$ ($E^0 = +0.80$ V) จงหาขั้วลบ ขั้วบวก และ $E^0_{cell}$

Mg มีศักย์มาตรฐานต่ำกว่า (ออกซิไดซ์ง่ายกว่า) → Mg เป็นขั้วลบ

$
\begin{aligned}
E^0_{cell} &= E^0_{cathode} - E^0_{anode} \\
           &= (+0.80) - (-2.37) = +3.17 \text{ V}
\end{aligned}
$

ค่าเป็นบวกมาก → ปฏิกิริยาเกิดได้เองดีมาก

**โจทย์ 2:** เขียนปฏิกิริยาที่ขั้วทั้งสองและปฏิกิริยารวมของเซลล์ Mg–Ag

- ขั้วลบ (ออกซิเดชัน): $\text{Mg} \rightarrow \text{Mg}^{2+} + 2e^-$
- ขั้วบวก (รีดักชัน): $\text{Ag}^+ + e^- \rightarrow \text{Ag}$ (ต้องคูณสองให้ e⁻ เท่ากัน)
- รวม: $\text{Mg} + 2\text{Ag}^+ \rightarrow \text{Mg}^{2+} + 2\text{Ag}$

**โจทย์ 3:** ทิศทางการเคลื่อนที่ของไอออนในสะพานเกลือของเซลล์ Zn–Cu เป็นอย่างไร?

ที่ถ้วยซ้าย (anode) Zn ละลายเป็น Zn²⁺ ทำให้**ไอออนบวกเกิน** → ไอออนลบ NO₃⁻ จากสะพานเกลือ**ไหลเข้าถ้วยซ้าย** ส่วนถ้วยขวา Cu²⁺ ลดลงเกิดเป็น Cu ทำให้**ไอออนลบเกิน** → ไอออนบวก K⁺ **ไหลเข้าถ้วยขวา**

จำง่าย: **ไอออนวิ่งสวนกันกับเครื่องหมาย** — ลบ (anion) → ไปหาขั้วลบ, บวก (cation) → ไปหาขั้วบวก

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **สลับขั้วตรงข้ามกับอิเล็กโทรซิส** — ในเซลล์กัลวานิก anode เป็น**ขั้วลบ** แต่ในเซลล์อิเล็กโทรซิส (ใช้ไฟภายนอก) anode เป็นขั้วบวก! ยึดหลัก AN OX / RED CAT ร่วมกับ "anode = ออกซิเดชันเสมอ" แล้วดูว่าเซลล์ชนิดไหน
> 2. **คิดว่าอิเล็กตรอนไหลในสารละลาย** — อิเล็กตรอนไหลเฉพาะ**สายไฟภายนอก**เท่านั้น ในสารละลายมีแต่การเคลื่อนที่ของ**ไอออน**
> 3. **ใช้เกลือที่ทำปฏิกิริยาในสะพานเกลือ** — เช่น ใช้ AgNO₃ ในเซลล์ที่มี Cu จะเกิดปฏิกิริยาแปลกปลอม ต้องเลือกเกลือเฉื่อย
> 4. **ลบเศษส่วนอิเล็กตรอนผิดตอนหาปฏิกิริยารวม** — คูณสมการขั้วให้จำนวน e⁻ เท่ากัน **แต่ห้าม**คูณ $E^0$ ด้วย! ศักย์มาตรฐานเป็นสมบัติเชิงคุณภาพ ไม่ขึ้นกับปริมาณสาร
> 5. **สับสน $E^0_{cell}$ กับสูตร +** — ใช้ $E^0_{cathode} - E^0_{anode}$ เสมอ ไม่ใช่บวกกัน
