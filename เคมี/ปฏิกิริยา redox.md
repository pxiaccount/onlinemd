# ปฏิกิริยา redox

> [!abstract] สรุปในหนึ่งบรรทัด
> ปฏิกิริยา redox คือปฏิกิริยาที่มี**การเปลี่ยนแปลงเลขออกซิเดชัน** — ตัวถูกออกซิไดซ์เสียอิเล็กตรอน (เลขเพิ่มขึ้น) พร้อมกับตัวถูกรีดิวซ์ได้รับอิเล็กตรอน (เลขลดลง) เกิดพร้อมกันเสมอ

$
\text{Oxidation: } \mathrm{loss\ of\ e^-} \qquad \text{Reduction: } \mathrm{gain\ of\ e^-}
$

## 🧠 ทำความเข้าใจ

ชื่อ **redox** มาจากคำว่า **Red**uction + **Ox**idation — แปลว่ามันเกิด 2 อย่างพร้อมกันในปฏิกิริยาเดียว

เปรียบเหมือนการโอนเงิน: เงิน (อิเล็กตรอน) ออกจากบัญชีคุณก็ต้องเข้าบัญชีคนอื่นพร้อมกันเสมอ — **อิเล็กตรอนไม่หายไปไหน** มันแค่เปลี่ยนเจ้าของ

จำง่าย ๆ:
- **OIL RIG** — *Oxidation Is Loss, Reduction Is Gain* (ของอิเล็กตรอน)
- ตัวถูกออกซิไดซ์ = **ตัวรีดิวซ์** (ให้อิเล็กตรอนเป็นคนลดให้คนอื่น)
- ตัวถูกรีดิวซ์ = **ตัวออกซิไดซ์** (รับอิเล็กตรอนจากคนอื่น)

ตัวอย่างใกล้ตัว: ของเหล็กเป็นสนิม — เหล็ก (Fe) ถูกออกซิไดซ์ อากาศ (O₂) ถูกรีดิวซ์ รวมถึงการเผาไหม้ การชาร์จแบตเตอรี่ และเซลล์กัลวานิก ล้วนเป็น redox ทั้งหมด

## ✏️ ตัวอย่างการคำนวณ

**ตัวอย่าง:** วิเคราะห์ปฏิกิริยา $\mathrm{Zn + Cu^{2+} \rightarrow Zn^{2+} + Cu}$

1. เขียนเลขออกซิเดชันของแต่ละธาตุ:
   - Zn: 0 → +2 (**เพิ่มขึ้น** = ถูกออกซิไดซ์, เสีย 2 e⁻)
   - Cu: +2 → 0 (**ลดลง** = ถูกรีดิวซ์, รับ 2 e⁻)
2. แยกครึ่งปฏิกิริยา:

$
\begin{aligned}
\mathrm{Zn} &\rightarrow \mathrm{Zn^{2+}} + 2\mathrm{e^-} \quad \text{(oxidation)} \\
\mathrm{Cu^{2+}} + 2\mathrm{e^-} &\rightarrow \mathrm{Cu} \quad \text{(reduction)}
\end{aligned}
$

3. สรุป: Zn เป็น**ตัวรีดิวซ์** Cu²⁺ เป็น**ตัวออกซิไดซ์** — อิเล็กตรอนถ่ายโอน 2 ตัวพอดี (สมดุลแล้ว)

> [!tip] ตรวจเร็วด้วยเลขออกซิเดชัน
> เทียบเลขออกซิเดชันก่อน–หลังของทุกธาตุ ถ้าธาตุไหน**เปลี่ยน** → เป็น redox ถ้าทุกธาตุเท่าเดิม → ไม่ใช่ redox (เช่น การแตกตัวของเกลือในน้ำ)

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **สับสนระหว่าง "ถูกออกซิไดซ์" กับ "ตัวออกซิไดซ์"** — ตัวที่ถูกออกซิไดซ์คือ*ตัวรีดิวซ์* ไม่ใช่ตัวออกซิไดซ์!
> 2. จำเลขออกซิเดชันของ O ไม่เป็น −2 เสมอไป — ใน H₂O₂ (เปอร์ออกไซด์) มีค่า −1
> 3. เช็กเลขอิเล็กตรอนในครึ่งปฏิกิริยาไม่เท่ากัน — ต้องคูณครึ่งปฏิกิริยาให้จำนวน e⁻ เท่ากันก่อนรวม
> 4. เผลอเรียกปฏิกิริยาที่ไม่มีการเปลี่ยนเลขออกซิเดชัน (เช่น กรด+เบส) ว่าเป็น redox

## 🏋️ แบบฝึกหัด

> [!question]- 1 ในปฏิกิริยา $\mathrm{2Mg + O_2 \rightarrow 2MgO}$ ธาตุใดถูกออกซิไดซ์ ธาตุใดถูกรีดิวซ์ และใครเป็นตัวออกซิไดซ์?
> > [!success]- เฉลย
> > - Mg: 0 → +2 → **ถูกออกซิไดซ์** (เสีย e⁻) เป็นตัวรีดิวซ์
> > - O: 0 → −2 → **ถูกรีดิวซ์** (รับ e⁻)
> > - **ตัวออกซิไดซ์คือ O₂** เพราะเป็นฝ่ายรับอิเล็กตรอนจาก Mg

> [!question]- 2 ปฏิกิริยาใดต่อไปนี้เป็นปฏิกิริยา redox: (ก) $\mathrm{NaOH + HCl \rightarrow NaCl + H_2O}$ (ข) $\mathrm{Fe + 2HCl \rightarrow FeCl_2 + H_2}$
> > [!success]- เฉลย
> > - **(ก) ไม่ใช่ redox** — Na(+1), O(−2), H(+1), Cl(−1) ค่าเท่าเดิมหมด (เป็นแค่ปฏิกิริยาสะเทิน)
> > - **(ข) เป็น redox** — Fe: 0 → +2 ถูกออกซิไดซ์, H: +1 → 0 ถูกรีดิวซ์

> [!question]- 3 ผสมสารละลาย Pb(NO₃)₂ กับ KI เกิดตะกอนสีเหลือง เขียนสมการและพิจารณาว่าเป็น redox หรือไม่
> > [!success]- เฉลย
> > สมการ: $\mathrm{Pb(NO_3)_2 + 2KI \rightarrow PbI_2\downarrow + 2KNO_3}$ (ตะกอนเหลือง = PbI₂)
> > เช็คเลขออกซิเดชัน: Pb +2→+2, I −1→−1, K +1→+1, N +5→+5, O −2→−2 — **ไม่มีใครเปลี่ยน**
> > **ไม่ใช่ redox** เป็นเพียงปฏิกิริยาแทนที่คู่ที่ตกตะกอน

> [!question]- 4 จุ่มลวด Mg ลงในสารละลาย ZnSO₄ เกิดสารสีเทาเงินเกาะลวดและลวด Mg กร่อน เขียนสมการและพิจารณาว่าเป็น redox หรือไม่
> > [!success]- เฉลย
> > สมการ: $\mathrm{Mg + ZnSO_4 \rightarrow MgSO_4 + Zn}$ (สีเทาเงิน = Zn ที่ถูกดันออก)
> > เช็ค: Mg 0→+2 **ถูกออกซิไดซ์**, Zn +2→0 **ถูกรีดิวซ์** → **เป็น redox** ✅
> > เหตุผล: Mg อยู่ในอนุกรมกิจกรรมสูงกว่า Zn จึงเสียอิเล็กตรอนแทนและดัน Zn²⁺ ออกจากสารละลาย

> [!question]- 5 Mg ทำปฏิกิริยากับ HCl และ ZnSO₄ ได้ ส่วน Zn ทำปฏิกิริยากับ HCl ได้แต่ทำกับ MgSO₄ ไม่ได้ — เขียนสมการและเรียงลำดับความสามารถเป็นตัวออกซิไดซ์ของ H⁺, Mg²⁺, Zn²⁺ และตัวรีดิวซ์ของ H₂, Mg, Zn
> > [!success]- เฉลย
> > **สมการ redox ที่เกิดขึ้น (3 ปฏิกิริยา):**
> > $\mathrm{Mg + 2HCl \rightarrow MgCl_2 + H_2}$ , $\mathrm{Mg + ZnSO_4 \rightarrow MgSO_4 + Zn}$ , $\mathrm{Zn + 2HCl \rightarrow ZnCl_2 + H_2}$
> > (Zn + MgSO₄ ไม่เกิด เพราะ Zn อ่อนกว่า Mg)
> > **อ่านข้อมูล:** Mg ชนะทั้ง H⁺ และ Zn²⁺ → เก่งสุด, Zn ชนะ H⁺ → กลาง, H₂ แพ้ทั้งคู่ → อ่อนสุด
> > **ตัวรีดิวซ์:** $\mathrm{Mg > Zn > H_2}$
> > **ตัวออกซิไดซ์ (กลับทิศ):** $\mathrm{Mg^{2+} < Zn^{2+} < H^+}$ — ตัวรีดิวซ์เก่งคู่กับตัวออกซิไดซ์อ่อนเสมอ

## 🎴 การ์ดทบทวน #flashcards

ปฏิกิริยา redox คืออะไร?::ปฏิกิริยาที่มีการเปลี่ยนแปลงเลขออกซิเดชัน — การออกซิไดซ์และรีดิวซ์เกิดพร้อมกันเสมอ

การออกซิไดซ์ (oxidation) คือการเสียหรือรับอิเล็กตรอน?::**เสีย**อิเล็กตรอน (เลขออกซิเดชันเพิ่มขึ้น) — OIL: Oxidation Is Loss

ตัวออกซิไดซ์ (oxidizing agent) ทำหน้าที่อะไร?::รับอิเล็กตรอนจากตัวอื่น และตัวมันเอง**ถูกรีดิวซ์**

เลขออกซิเดชันของ O ใน H₂O₂ เป็นเท่าไร?::−1 (คำนวณ: 2(+1) + 2x = 0 → x = −1) ส่วนในสารประกอบทั่วไปเป็น −2

$\mathrm{Zn + Cu^{2+} \rightarrow Zn^{2+} + Cu}$ ใครเป็นตัวรีดิวซ์?::Zn เพราะเสียอิเล็กตรอน (0 → +2) และทำให้ Cu²⁺ ถูกรีดิวซ์

วิธีเช็กว่าปฏิกิริยาเป็น redox หรือไม่?::เทียบเลขออกซิเดชันก่อน–หลังของทุกธาตุ ถ้ามีธาตุใดค่าเปลี่ยน = เป็น redox
