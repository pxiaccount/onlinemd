> **AN OX** — **AN**ode = **OX**idation (แอโนดเกิดการถูกออกซิไดซ์) / **RED CAT** — **RED**uction ที่ **CAT**hode (แคโทดเกิดการถูกรีดิวซ์) — อิเล็กตรอนไหลจากแอโนด → แคโทดเสมอ

## ส่วนที่ 1: เลขออกซิเดชัน (ข้อ 1–4)

> [!question]- ข้อ 1: เลขออกซิเดชันของ Mn ใน KMnO₄ เท่ากับเท่าไร
> > [!success]- เฉลย
> > K มีเลขออกซิเดชัน +1, O มี −2 ต่ออะตอม
> >
> > $(+1) + x + 4(-2) = 0$
> > $x = +7$
> >
> > ตอบ: Mn มีเลขออกซิเดชัน **+7**

> [!question]- ข้อ 2: เลขออกซิเดชันของ Cr ใน Na₂Cr₂O₇ เท่ากับเท่าไร
> > [!success]- เฉลย
> > Na = +1, O = −2
> >
> > $2(+1) + 2x + 7(-2) = 0$
> > $2x = +12 \Rightarrow x = +6$
> >
> > ตอบ: Cr มีเลขออกซิเดชัน **+6**

> [!question]- ข้อ 3: เลขออกซิเดชันของ S ใน SO₃²⁻ และ SO₄²⁻ ต่างกันเท่าไร
> > [!success]- เฉลย
> > ใน SO₃²⁻: $x + 3(-2) = -2 \Rightarrow x = +4$
> > ใน SO₄²⁻: $x + 4(-2) = -2 \Rightarrow x = +6$
> >
> > ตอบ: ต่างกัน **2** (+4 เทียบกับ +6)

> [!question]- ข้อ 4: ธาตุไอโอดีนมีเลขออกซิเดชันสูงสุดในสารใด: I₂, IO₃⁻, หรือ HI
> > [!success]- เฉลย
> > - I₂ (ธาตุอิสระ) = 0
> > - IO₃⁻: $x + 3(-2) = -1 \Rightarrow x = +5$
> > - HI: $x + (+1) = 0 \Rightarrow x = -1$
> >
> > ตอบ: **IO₃⁻** (+5 สูงสุด)

## ส่วนที่ 2: ตัวถูกออกซิไดซ์ / ถูกรีดิวซ์ (ข้อ 5–7)

> [!question]- ข้อ 5: ในปฏิกิริยา Zn + Cu²⁺ → Zn²⁺ + Cu สิ่งใดเป็นตัวถูกรีดิวซ์
> > [!success]- เฉลย
> > - Zn → Zn²⁺ + 2e⁻ : สูญเสียอิเล็กตรอน = ถูกออกซิไดซ์ (ตัวถูกออกซิไดซ์คือ Zn... ระวัง! ตัวรับอิเล็กตรอนเท่านั้น)
> > - Cu²⁺ + 2e⁻ → Cu : รับอิเล็กตรอน = **ถูกรีดิวซ์**
> >
> > ตอบ: **Cu²⁺** คือสารที่ถูกรีดิวซ์ (และเป็น *ตัวออกซิไดซ์* เพราะรับอิเล็กตรอนจาก Zn)

> [!question]- ข้อ 6: Fe + H₂SO₄ → FeSO₄ + H₂ สารใดเป็นตัวออกซิไดซ์
> > [!success]- เฉลย
> > Fe → Fe²⁺ + 2e⁻ (ถูกออกซิไดซ์) และ 2H⁺ + 2e⁻ → H₂ (ถูกรีดิวซ์)
> >
> > ตอบ: **H₂SO₄** (หรือ H⁺) เป็นตัวออกซิไดซ์ เพราะรับอิเล็กตรอน

> [!question]- ข้อ 7: ข้อใดเป็นปฏิกิริยา redox: (ก) HCl + NaOH → NaCl + H₂O (ข) 2Na + Cl₂ → 2NaCl
> > [!success]- เฉลย
> > (ก) เป็นปฏิกิริยาสมดุลกรด–เบส ไม่มีการเปลี่ยนเลขออกซิเดชัน → **ไม่ใช่ redox**
> > (ข) Na: 0 → +1 (ถูกออกซิไดซ์), Cl: 0 → −1 (ถูกรีดิวซ์) → **เป็น redox**

## ส่วนที่ 3: เซลล์กัลวานิก (ข้อ 8–12)

ใช้ข้อมูลศักย์มาตรฐาน (E°) ต่อไปนี้:

| ครึ่งปฏิกิริยา | E° (V) |
|---|---|
| Zn²⁺ + 2e⁻ → Zn | −0.76 |
| Cu²⁺ + 2e⁻ → Cu | +0.34 |
| Ag⁺ + e⁻ → Ag | +0.80 |

> [!question]- ข้อ 8: เซลล์ Zn|Zn²⁺||Cu²⁺|Cu ขั้วใดเป็นแอโนด
> > [!success]- เฉลย
> > โลหะที่มี E° ต่ำกว่า (ถูกออกซิไดซ์ง่ายกว่า) เป็นแอโนด
> >
> > ตอบ: **Zn** เป็นแอโนด (ขั้วลบ) — มันสูญเสียอิเล็กตรอนเอง

> [!question]- ข้อ 9: คำนวณค่า EMF มาตรฐาน (E°cell) ของเซลล์ข้อ 8
> > [!success]- เฉลย
> > $E°_{cell} = E°_{cathode} - E°_{anode} = (+0.34) - (-0.76) = +1.10$ V
> >
> > ตอบ: **1.10 โวลต์** (ค่าเป็นบวก = ปฏิกิริยาเกิดได้เอง)

> [!question]- ข้อ 10: ถ้าเปลี่ยนขั้วขวาเป็น Ag⁺|Ag (เทียบกับแอโนด Zn) E°cell จะเป็นเท่าไร
> > [!success]- เฉลย
> > $E°_{cell} = (+0.80) - (-0.76) = +1.56$ V
> >
> > ตอบ: **1.56 โวลต์** — สูงกว่า Cu เพราะ Ag⁺ รับอิเล็กตรอนเก่งกว่า

> [!question]- ข้อ 11: อิเล็กตรอนไหลทางไหน และสะพานเกลือมีหน้าที่อย่างไร
> > [!success]- เฉลย
> > - อิเล็กตรอนไหลจาก **แอโนด (Zn) → แคโทด (Cu)** ผ่านสายไฟภายนอก
> > - สะพานเกลือเติมไอออนเข้าสู่ครึ่งเซลล์ เพื่อ**รักษาความเป็นกลางทางไฟฟ้า** ถ้าไม่มีจะสะสมประจุบวก/ลบที่ถ้วยใดถ้วยหนึ่ง และกระแสจะหยุด
> >
> > ตอบ: อิเล็กตรอนไหล Zn → Cu / สะพานเกลือปิดวงจรและคงความเป็นกลางของประจุ

> [!question]- ข้อ 12: ขั้ว Zn จะหนาขึ้นหรือบางลง และเพราะอะไร
> > [!success]- เฉลย
> > ที่แอโนด (Zn): Zn → Zn²⁺ + 2e⁻ อะตอม Zn จากขั้วหลุดเป็นไอออนลงสารละลาย
> >
> > ตอบ: ขั้ว Zn **บางลง** เพราะถูกออกซิไดซ์ ส่วนขั้ว Cu จะหนาขึ้นเพราะมี Cu จับตัวที่แคโทด

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. **สับสน "ตัวถูกออกซิไดซ์" กับ "ตัวออกซิไดซ์"** — ตัวถูกออกซิไดซ์ (ตัวให้อิเล็กตรอน) = ตัวรีดิวซ์ / ตัวออกซิไดซ์ (ตัวรับอิเล็กตรอน) = ตัวถูกรีดิวซ์ สลับชื่อกันบ่อยมาก!
> 2. **E°cell ห้ามคูณจำนวนอิเล็กตรอน** — แม้ต้องคูณสมการครึ่งปฏิกิริยาเพื่อให้อิเล็กตรอนเท่ากัน E° ก็ยังใช้ค่าเดิม (เป็นสมบัติเชิงคุณภาพ ไม่ใช่ปริมาณ)
> 3. **แอโนดคือขั้วลบในเซลล์กัลวานิก** แต่เป็นขั้วบวกในเซลล์อิเล็กโทรไลซิส — อย่าใช้ "ลบ/บวก" ตัดสิน ให้ดูว่าขั้วไหนถูกออกซิไดซ์
> 4. **เลขออกซิเดชันรวมต้องเป็น 0 ในสารประกอบกลาง** และเท่ากับประจุไอออนในไอออนพอลิอะตอม
