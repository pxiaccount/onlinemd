# 🧪 เคมี

ยินดีต้อนรับสู่โฟลเดอร์เคมี — เนื้อหา redox และเคมีไฟฟ้าเรียงตามลำดับการเรียน

## 📚 หัวข้อทั้งหมด

### 🔄 ปฏิกิริยา redox

- 🔄 [[ปฏิกิริยา redox]] — นิยาม เลขออกซิเดชัน ตัวถูกออกซิไดซ์/ถูกรีดิวซ์
- ✍️ [[การเขียนสมการปฏิกิริยา redox]] — ขั้นตอนเขียนสมการ ion–electron
- 💧 [[การเติมน้ำและไอออนในการดุล redox]] — เมื่อไรเติมอะไร ในสารละลายกรด/เบส
- ⚖️ [[วิธีดุลด้วยครึ่งปฏิกิริยา]] — แยกเป็นครึ่งปฏิกิริยาแล้วค่อยรวม

### 🔋 เคมีไฟฟ้า

- 🔋 [[เซลล์กัลวานิก]] — โครงสร้างเซลล์ ขั้วบวก–ขั้วลบ การไหลของอิเล็กตรอน
- 🧂 [[ตารางตะกอนและกฎการละลาย]] — จำง่าย ทำนายตะกอนในปฏิกิริยา

### ✏️ แบบฝึกหัด

- 🏋️ [[แบบฝึกหัดการดุลสมการ redox พร้อมเฉลย]] — ฝึกดุลสมการทีละขั้น
- 📝 [[โจทย์เคมีไฟฟ้าง่าย ๆ พร้อมเฉลย]] — 12 ข้อ เลขออกซิเดชัน • redox • เซลล์กัลวานิก
