## 📝 โจทย์และเฉลย

> [!question]- 2 (เบส) ดุล $\mathrm{ClO^- + I_2 \rightarrow IO_3^- + Cl^-}$
> > [!success]- เฉลย
> > ครึ่งออกซิเดชัน (I: 0→+5): I₂ + 12OH⁻ → 2IO₃⁻ + 6H₂O + 10e⁻
> >
> > (ขาด O 6 ขวา → เบสเติม 12OH⁻ ขวา? — ใช้ทางลัด: แบบกรดคือ I₂ + 6H₂O → 2IO₃⁻ + 12H⁺ + 10e⁻ แล้วเติม 12OH⁻ สองข้าง ตัด H₂O ได้แบบเบสด้านบน)
> >
> > ครึ่งรีดักชัน (Cl: +1→−1): ClO⁻ + H₂O + 2e⁻ → Cl⁻ + 2OH⁻ ×5
> >
> > รวม ตัด 10e⁻ และตัด OH⁻/H₂O ซ้ำ (OH⁻ ซ้าย 12−10=2, H₂O ขวา 6−5=1):
> >
> > $$\mathrm{I_2 + 2OH^- + 5ClO^- \rightarrow 2IO_3^- + H_2O + 5Cl^-}$$
> >
> > ตรวจประจุ: −2−5 = −7 = −2−5 ✅
