# วิธีดุลสมการ redox ด้วยครึ่งปฏิกิริยา

> [!abstract] สรุปในหนึ่งบรรทัด
> แยกสมการ redox เป็น 2 ครึ่ง (ครึ่งเสีย e⁻ กับครึ่งรับ e⁻) → ดุลแต่ละครึ่งแยกกัน (อะตอมหลัก → O → H → ประจุ) → คูณทวีคูณร่วมน้อยให้ e⁻ เท่ากัน → รวมแล้วตัด e⁻

## 🧠 ทำความเข้าใจ

สมการ redox ต้องดุล 2 อย่างพร้อมกัน: **อะตอม** และ**ประจุ (e⁻)** — ดุลพร้อมกันทีเดียวจะมึนหัวมาก วิธีครึ่งปฏิกิริยาเลย "ตัดปัญหาออกเป็นสองชิ้นเล็ก" ดุลทีละชิ้นแล้วค่อยประกอบกลับ

เปรียบเหมือนซ่อมจักรยาน: แยกล้อหน้า-ล้อหลังซ่อมทีละชิ้นง่ายกว่าจับทั้งคันซ่อมพร้อมกัน

**กฎเหล็กที่ต้องจำ:**

- e⁻ ของ**ครึ่งออกซิเดชัน ต้องอยู่ฝั่งขวา** (ผลิตออกมา)
- e⁻ ของ**ครึ่งรีดักชัน ต้องอยู่ฝั่งซ้าย** (รับเข้ามา)
- ถ้าเขียนแล้ว e⁻ ผิดฝั่ง = รีดักชัน/ออกซิเดชันสลับกัน ให้กลับไปเช็คเลขออกซิเดชันใหม่

**ตารางเติมอะไร (หัวใจของขั้นดุลอะตอม):**

| สภาพ | ขาด O → เติม | ขาด H → เติม |
|---|---|---|
| กรด | H₂O ฝั่งขาด O | H⁺ ฝั่งขาด H |
| เบส | 2OH⁻ ต่อ O ที่ขาด 1 | H₂O ฝั่งขาด H |

## ✏️ ตัวอย่างเดินทีละขั้น (สภาพกรด)

**โจทย์:** ดุล $\mathrm{MnO_4^- + Fe^{2+} \rightarrow Mn^{2+} + Fe^{3+}}$

**ขั้น 1 — แยกครึ่งปฏิกิริยา** (ดูจากเลขออกซิเดชัน: Mn +7→+2 ลด = รีดักชัน, Fe +2→+3 เพิ่ม = ออกซิเดชัน)

$$\mathrm{Fe^{2+} \rightarrow Fe^{3+}}$$

$$\mathrm{MnO_4^- \rightarrow Mn^{2+}}$$

**ขั้น 2 — ดุลอะตอมหลัก** (Fe กับ Mn ดุลอยู่แล้ว ข้าม)

**ขั้น 3 — ดุล O แล้วดุล H** (สภาพกรด)

- ครึ่ง Mn ขาด O 4 ตัวฝั่งขวา → เติม 4H₂O ขวา

$$\mathrm{MnO_4^- \rightarrow Mn^{2+} + 4H_2O}$$

- ขาด H 8 ตัวฝั่งขวา → เติม 8H⁺ ซ้าย

$$\mathrm{MnO_4^- + 8H^+ \rightarrow Mn^{2+} + 4H_2O}$$

**ขั้น 4 — ดุลประจุด้วย e⁻**

- ซ้าย = −1 + 8 = +7, ขวา = +2 → ต้องการลดซ้าย 5 → เติม 5e⁻ **ฝั่งซ้าย** (ถูกต้อง เพราะเป็นครึ่งรีดักชัน)

$$\mathrm{MnO_4^- + 8H^+ + 5e^- \rightarrow Mn^{2+} + 4H_2O}$$

- ครึ่ง Fe: +2 → +3 → เติม e⁻ **ฝั่งขวา**

$$\mathrm{Fe^{2+} \rightarrow Fe^{3+} + e^-}$$

**ขั้น 5 — คูณทวีคูณร่วมน้อยให้ e⁻ เท่ากัน**

- e⁻ คือ 5 กับ 1 → คูณครึ่ง Fe ด้วย 5

$$\mathrm{5Fe^{2+} \rightarrow 5Fe^{3+} + 5e^-}$$

**ขั้น 6 — รวมแล้วตัด e⁻**

$$\mathrm{MnO_4^- + 8H^+ + 5Fe^{2+} \rightarrow Mn^{2+} + 4H_2O + 5Fe^{3+}}$$

**ตรวจ:** อะตอม Mn 1=1, Fe 5=5, O 4=4, H 8=8

ประจุซ้าย = −1+8+10 = +17, ขวา = +2+15 = +17 ✅

## ✏️ ตัวอย่างสภาพเบส

**โจทย์:** ดุล $\mathrm{MnO_4^- + S^{2-} \rightarrow MnO_2 + S}$

**ขั้น 1 — แยก:** Mn +7→+4 = รีดักชัน / S −2→0 = ออกซิเดชัน

**ขั้น 2–3 — ดุล O และ H (สภาพเบส):**

- ครึ่งรีดักชัน: MnO₄⁻ → MnO₂ — ซ้ายเกิน O 2 ตัว

สภาพเบส: ซ้ายเกิน O → เติม 2H₂O ซ้าย (รับ H) แล้ว H เกิน 4 → เติม 4OH⁻ ขวา

$$\mathrm{MnO_4^- + 2H_2O \rightarrow MnO_2 + 4OH^-}$$

- ดุลประจุ: ซ้าย −1, ขวา −4 → เติม 3e⁻ ซ้าย

$$\mathrm{MnO_4^- + 2H_2O + 3e^- \rightarrow MnO_2 + 4OH^-}$$

- ครึ่งออกซิเดชัน: S²⁻ → S (O, H ไม่มี ข้าม) ดุลประจุ: เติม 2e⁻ ขวา

$$\mathrm{S^{2-} \rightarrow S + 2e^-}$$

**ขั้น 4 — คูณ LCM:** e⁻ คือ 3 กับ 2 → คูณครึ่งแรก ×2, ครึ่งหลัง ×3

**ขั้น 5 — รวม ตัด 6e⁻:**

$$\mathrm{2MnO_4^- + 4H_2O + 3S^{2-} \rightarrow 2MnO_2 + 8OH^- + 3S}$$

**ตรวจ:** O ซ้าย 8+4=12, ขวา 4+8=12 ✅ ประจุซ้าย −2−6=−8 = ขวา −8 ✅

> [!tip] ทางลัดภาวะเบส
> ดุลแบบกรดให้จบก่อน → เติม OH⁻ **ทั้งสองข้าง**จน H⁺ หมด (H⁺ + OH⁻ → H₂O) → ตัด H₂O ที่ซ้ำสองข้าง ได้คำตอบเบสทันที

## ⚠️ ข้อควรระวัง

> [!warning] ข้อผิดพลาดที่พบบ่อย
> 1. e⁻ วางผิดฝั่ง — ออกซิเดชัน e⁻ ต้องขวา รีดักชัน e⁻ ต้องซ้ายเสมอ
> 2. คูณเฉพาะสารที่มี e⁻ แต่ลืมคูณสารอื่นในครึ่งปฏิกิริยาเดียวกัน (ต้องคูณ**ทุกตัว**ในครึ่งนั้น)
> 3. รวมแล้วลืมตัด H₂O / OH⁻ / H⁺ ที่ปรากฏทั้งสองข้าง
> 4. สภาพเบสแต่เหลือ H⁺ ในคำตอบสุดท้าย = ผิดแน่นอน
> 5. ไม่ตรวจประจุรวมท้ายสุด — ใช้เวลาแค่ 10 วินาทีแต่จับผิดได้แทบทุกครั้ง
